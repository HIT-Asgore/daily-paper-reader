## 摘要
无模型强化学习算法（如近端策略优化PPO）将环境视为黑箱，通过采样奖励估计策略梯度；这一过程需要数百万次交互，且依赖于高方差的优势估计。当环境动力学可微时，回报是策略参数的端到端可微函数，从而能够通过模拟进行反向传播实现精确梯度计算。我们将此方法称为分析策略梯度（APG），并在四个动力学复杂度递增的连续控制任务上将其与PPO进行比较：一维点质量目标到达任务、带有避障的二维点质量导航任务、二维刚体T形块推动任务以及7自由度Franka FR3末端执行器到达任务。两种算法共享相同的模型架构、观测归一化和优化器设置。为解耦样本效率与计算效率，我们设计了一个多轴评估协议，记录性能与环境步数和梯度步数的关系。我们提出了一种分段反向传播方案，结合蒙特卡洛和基于评论家的自举模式，以缓解长视界任务中的梯度退化问题，并针对分段长度和自举策略进行了消融实验。

## Abstract
Model-free reinforcement learning algorithms such as Proximal Policy Optimization (PPO) treat the environment as a black box, estimating policy gradients from sampled rewards; this process demands millions of interactions and relies on high-variance advantage estimates. When environment dynamics are differentiable, the return is an end-to-end differentiable function of the policy parameters, enabling exact gradient computation via backpropagation through simulation. We term this approach Analytic Policy Gradients (APG) and evaluate it against PPO on four continuous control tasks of increasing dynamical complexity: a one-dimensional point-mass target-reaching task, a 2D point-mass navigation task with obstacle avoidance, a 2D rigid-body T-block pushing task, and a 7-DOF Franka FR3 end-effector reaching task. Both algorithms share identical model architectures, observation normalization, and optimizer settings. To decouple sample efficiency from compute efficiency, we design a multi-axis evaluation protocol that records performance against environment steps and gradient steps. We report a segmented backpropagation scheme with MC and critic-based bootstrap modes that mitigates gradient degradation on long-horizon tasks, and present ablations over segment length and bootstrap strategy.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：假设环境转移函数 \(T(s,a)\) 和奖励函数 \(R(s,a)\) 均可微，则有限时域折扣回报 \(J(\theta)\) 对策略参数 \(\theta\) 的梯度可通过反向传播整个轨迹精确计算（不需要任何优势估计）。
- **关键技术细节**：
  - **重参数化采样**：动作 \(a_t = \mu_\theta(s_t) + \sigma_\theta \odot \epsilon_t\)，使得梯度可流过均值和标准差。
  - **总导数递归**：通过递归式 \(ds_t/d\theta = (\partial T/\partial a_{t-1})(da_{t-1}/d\theta) + (\partial T/\partial s_{t-1})(ds_{t-1}/d\theta)\) 实现自动微分的BPTT。
  - **分段反向传播（Segmented Backpropagation）**：针对长时域任务，将全轨迹分为长度 \(L_{seg}\) 的片段，在片段边界断开计算图，并使用自举（bootstrap）估计未来回报。
    - **MC Bootstrap**：利用后续片段的真实（detached）奖励反向累加作为未来回报估计。
    - **Critic Bootstrap**：使用学习到的价值函数 \(V_\phi(s)\) 估计片段边界后的未来回报。
  - **梯度桥接（Gradient Bridge）**：对非原生PyTorch可微的物理引擎（如基于NVIDIA Warp/Newton的FrankaReach），实现自定义`torch.autograd.Function`，将Warp的自动微分与PyTorch图连接。
  - **训练流程（Algorithm 1）**：状态保持，每梯度步执行一次未截断或分段的完整rollout（保持计算图），计算损失 \(L = -\frac{1}{N}\sum_i \sum_k (G_k + b_k)\)，反向传播并更新。
- **与PPO的关键区别**：APG不需要存储buffer、多epoch更新、GAE、重要性采样或熵正则化；梯度直接来自环境仿真图。

### 6. 论文的主要结论与发现

1. **梯度质量优势**：APG在四个环境上均达到比PPO更高的最终回合回报（Table 10: PointMassNavigate: APG -14.59 vs PPO -64.89; FrankaReach: APG 0.73 vs PPO -0.09）。严格任务成功率在简单任务（PointMassSimple, PushT）达到100%，但在困难任务（PointMassNavigate 20%, FrankaReach 20%）仍仅为部分，说明高回报不自动等于高成功率。
2. **样本与学习效率极大提升**：达到性能阈值所需梯度步数：APG相比PPO节省3.9倍（PushT）至15.9倍（FrankaReach）（Table 12）。环境步数上也节省1.07倍至4.34倍（Table 11）。

4. **梯度桥接可行性**：通过自定义`torch.autograd.Function`成功将Warp/Newton的自动微分接入PyTorch，证明APG可应用于非原生PyTorch可微的GPU物理引擎。

- **统一比较框架**：PPO和APG使用完全相同的代码基、架构、超参数，确保比较公平。

- **梯度桥接工程实现**：解决了外部物理引擎与PyTorch自动微分的连接问题，扩展了APG的应用范围。
- **开源环境与代码**：公开了四个环境及完整实现，有助于复现和后续研究。

### 8. 不足与局限（实验覆盖、偏差风险、应用限制）

- **环境可微性限制**：APG从根本上要求环境动力学可微，排除了真实世界训练、非可微物理（如离散碰撞、接触摩擦不稳定）等场景。
- **长时域梯度退化**：尽管采用分段方案，但vanishing/exploding gradient问题仍然存在，且对分段长度敏感（尤其Critic Bootstrap）。
