## 摘要
长视界任务在真实世界的机器人部署中很常见，但针对此类任务的故障检测仍未被充分探索。检测长视界机器人任务中的故障尤其具有挑战性，因为故障开始往往模糊不清，且通常缺乏密集的时间注释。我们提出了Foresight，一种故障检测框架，利用来自动作条件世界模型的潜在表示来监控操作轨迹。Foresight仅使用最终任务级别的成功或失败标签进行训练。通过利用预测性世界模型嵌入，我们的方法为不同策略下的故障检测提供了一个统一框架。我们进一步使用函数共形预测（FCP）来自适应地校准检测阈值。我们在LIBERO-Long、ManiSkill-Long和BEHAVIOR-1K模拟环境中，使用最先进的视觉-语言-动作策略评估了Foresight，与最先进的故障检测方法进行了比较，并在真实机器人上使用ReactorX-200机械臂的三个长视界任务和Franka机械臂的一个任务进行了验证。我们的结果表明，动作条件世界模型嵌入为长视界操作中的可靠故障监控提供了一种可扩展的表示。

## Abstract
Long-horizon tasks are common in real-world robotic deployments, yet failure detection for such tasks remains underexplored. Detecting failures in long-horizon robotic tasks is particularly challenging because failure onset is often ambiguous and dense temporal annotations are typically unavailable. We present Foresight, a failure detection framework that monitors manipulation trajectories using latent representations from an action-conditioned world model. Foresight is trained using only final task-level success or failure labels. By leveraging predictive world-model embeddings, our method provides a unified framework for failure detection across different policies. We further use functional conformal prediction (FCP) to calibrate detection thresholds adaptively. We evaluate Foresight with state-of-the-art vision-language-action policies in simulation on LIBERO-Long, ManiSkill-Long, and BEHAVIOR-1K, compare it against state-of-the-artfailure detection methods, and validate it on real robots with three long-horizon tasks on a ReactorX-200 arm and one task on a Franka arm. Our results suggest that action-conditioned world-model embeddings provide a scalable representation for reliable failure monitoring in long-horizon manipulation.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：长视界（long-horizon）机器人操作任务中的**故障检测（failure detection）** 极具挑战性。传统故障检测方法大多针对短视界任务、孤立视觉异常或依赖策略内部置信信号，无法应对长视界任务中故障起始模糊、缺乏密集时间标注的问题。
- **核心难点**：长视界任务中，相同的视觉状态在不同动作历史下意义完全不同（如物体放在桌上在抓取前是预期的，但在抓取指令后是失败的）。小偏差可能累积并最终不可逆，因此检测器必须结合动作信息判断轨迹是否与预期进展一致。
- **整体含义**：提出一种**统一、可跨策略**的故障检测框架，仅需轨迹级的成功/失败标签，无需策略内部状态或不确定性估计，利用**动作条件世界模型（action-conditioned world model）** 的潜在表示来监控操作轨迹，为长视界操作提供可靠、可扩展的监控方案。

## 2. 方法论：核心思想与关键技术细节
- **核心思想**：使用**V-JEPA 2-AC**（动作条件版本的世界模型）提取紧凑的、任务相关的动作条件潜在特征，这些特征编码了动作-场景变化的依赖关系，作为故障检测的输入信号。通过因果序列模型输出每步故障分数，并用功能共形预测（FCP）自适应校准阈值。

- **三阶段流程**：
  - **Stage 1: 微调动作条件世界模型（WM-AC）**：冻结V-JEPA 2-AC的视觉编码器，仅训练**动作条件预测器（action-conditioned predictor）**。训练使用机器人操作轨迹（图像序列+动作），采用教师强制和自回归展开组合损失。
  - **Stage 2: 故障分数函数训练**：
    - 对每个时间步t，世界模型编码当前观察上下文（8帧滑动窗口）得到**隐藏潜在 $z_h^t$**（当前观测特征），并通过动作预测器基于策略预测的动作块 $A_t$ 得到**预测潜在 $z_p^t$**（期望的未来场景特征）。
    - 将 $z_p^t$ 加上位置编码作为时间步令牌 $u_t$，输入**因果Transformer**（或MLP/LSTM），输出每步故障分数 $s_t \in [0,1]$。训练使用轨迹级标签（每步继承整体标签，并施加早期检测加权）。
  - **Stage 3: 共形预测校准与部署**：在成功的校准rollout上，估计平均分数轨迹 $\mu_t$ 和时变调制项 $\sigma_t$，构造非一致性分数 $R_i = \sup_t (s_t^{(i)} - \mu_t)/\sigma_t$，取 $(1-\alpha)$ 分位数 $\hat{q}$，得到时变阈值 $\delta_t = \mu_t + \hat{q}\sigma_t$。当 $s_t \geq \delta_t$ 时触发报警。

- **关键细节**：
  - 世界模型视觉编码器冻结；动作预测器从零训练。
  - 隐含潜在 $z_h$ 与预测潜在 $z_p$ 的消融表明 $z_p$ 更有效，因为它捕捉了动作-状态一致性。
  - 检测器架构：因果Transformer含2层、4头注意、隐藏维度256，训练300 epoch。

    - **ManiSkill-Long**：4个任务（如堆叠6个立方体），平均1484步，使用π0-FAST。
    - **BEHAVIOR-1K**：4个移动操作任务（如放置捕鼠器、煮热狗），平均8557步，使用π0.5改进版。
  - **真实机器人**：
    - **ReactorX-200**臂：3个桌面整理任务，使用ACT、π0.5、SmolVLA策略。
    - **Franka**臂：1个玩具拾取任务，使用GR00T N1.5策略。

- **对比方法**：

## 6. 主要结论与发现
- **结论**：Foresight在所有基准上（模拟和真实）均优于或持平于最先进方法，尤其在最长horizon的BEHAVIOR-1K上提升显著（BalAcc 0.78 vs 最佳基线0.64，提升0.14；ROC-AUC 0.76 vs 0.72）。
- **关键发现**：

  - 因果Transformer作为检测器优于MLP和LSTM，说明序列建模对长时序监控重要。
  - 跨策略泛化可行但不对称，取决于训练策略是否覆盖目标策略的行为和故障模式。
  - V-JEPA 2-AC优于Cosmos-Predict2.5-2B（基于扩散的世界模型），表明潜在空间预测比像素级预测更适合故障检测。

## 7. 优点
1. **无需策略内部状态**：仅需观测和动作，可应用于任意VLA或visuomotor策略，实现统一监控。
2. **仅需轨迹级标签**：无需密集时间故障标注，降低数据标注成本。
3. **动作条件预测潜在**：利用世界模型预测未来状态，天然捕捉动作-状态一致性，适合长视界故障累积检测。
4. **共形预测阈值校准**：提供统计保证控制假阳性率，且阈值可适应时变分数分布。
5. **跨策略泛化能力**：训练于一种策略的检测器可迁移到另一种策略（尽管有不对称性）。
6. **全面实验验证**：覆盖多个仿真基准、真实机器人、多种策略，且包括消融和泛化实验，结果可信。

## 8. 不足与局限
1. **计算成本高**：世界模型骨干推理约183 ms/步（在H200上），不适合高反应性或敏捷控制任务（如实时闭环100Hz），需要在计算资源和监控精度间权衡。
2. **共形预测假设依赖**：统计保证要求校准数据与部署数据同分布；在分布漂移（如环境变化、策略更新）下假警报控制可能失效。
3. **跨策略泛化实验有限**：仅少量迁移组合，且不对称性未深入分析（为何某些方向差），可进一步研究策略行为覆盖对迁移的影响。
4. **任务覆盖不足**：仅评估操作任务（桌面、拾放、堆叠、移动操作），未涉及复杂交互（如装配、开门）、动态环境、多机器人协作等场景。
5. **真实任务长度有限**：真实实验平均约1000-1700步，未验证超长horizon（如BEHAVIOR-1K的8000+步）下的在线部署性能。
6. **未考虑传感器噪声与延迟**：真实部署中相机噪声、动作执行误差等可能影响世界模型预测质量，文中未讨论鲁棒性。
7. **缺乏与基于规则/监督方法的比较**：如基于状态估计的阈值方法（若可获取真实状态），但文中未包括此类基线。
