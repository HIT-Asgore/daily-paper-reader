## 摘要
世界动作模型（WAM）已成为具身智能的一种新的强大范式，学习与动作相关的视觉动态，显著增强了泛化性和鲁棒性。然而，现有的WAM在处理长时间跨度的机器人操作任务时，仍然难以有效利用任务相关的记忆。为了解决这个问题，我们提出了HiMem-WAM，一种分层记忆门控WAM，它集成了以运动为中心的潜在动作、高层技能潜在变量以及边界触发的记忆更新。具体地，我们开发了一个分层潜在动作框架，联合学习低层运动和高层技能潜在变量，提供了结构化的时间抽象。同时，一个边界感知的记忆门在预测的技能转换处写入紧凑的任务状态，使得无需在测试时生成未来视频或光流估计即可进行因果推理。在LIBERO、LIBERO-PLUS、RMBench以及真实世界任务上的评估表明，HiMem-WAM的分层潜在变量提升了部署扰动下的鲁棒性，而记忆模块显著有益于依赖记忆的长时间跨度操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 将策略分解为三个层次：高层技能选择、低层隐动作展开、动作解码。同时引入外部记忆库，仅在检测到技能转换（boundary）时写入紧凑任务状态，实现稀疏、事件驱动的记忆更新。

### 关键技术细节
1. **低层隐动作（Low-Level Latent Actions）**：
   - 使用多视角光流（DPFlow）作为中间监督，训练一个变分分词器（variational tokenizer）将短时上下文（当前/下一帧观测、本体感觉、指令、光流）编码为低层隐变量 \(z^l_t\)。
   - 损失函数包括光流重建、动作对齐（若标签可用）和KL散度正则化。分词器训练后冻结，用于离线提取所有轨迹的低层隐序列 \(Z^l\)。

2. **高层技能隐变量（High-Level Skill Latents）**：
   - 在低层隐序列上执行分层聚类：通过边界预测器（dissimilarity score）发现技能转换点，并对每个技能段进行注意力池化，得到高层隐变量 \(z^h\)（技能表示）。
   - 通过反向展开将高层技能标签映射回每个时间步，得到每步的技能目标 \(\bar{z}^h_t\) 和边界标签 \(\bar{b}_t\)。

3. **记忆门控模块（Memory-Gated Module）**：
   - **读门**：从当前状态 \(x_t\) 中检索外部记忆库 \(M_t\)，通过注意力得到记忆上下文 \(c^m_t\)，再用可学习的读门 \(\alpha^r_t\) 控制注入程度，形成记忆适应状态 \(\tilde{x}_t\)。
   - **规划器**：使用Qwen3-VL-4B-Instruct模型，基于 \(\tilde{x}_t\) 预测当前技能 \(\hat{z}^h_t\) 和边界分数 \(\hat{b}_t\)。
   - **执行器**：基于 \(\tilde{x}_t\) 和 \(\hat{z}^h_t\) 预测低层隐动作块 \(\hat{Z}^l_{t:t+K-1}\)，再通过动作解码器得到实际控制指令。
   - **写门**：根据 \(\tilde{x}_t, \hat{z}^h_t, \hat{b}_t\) 计算写门 \(\alpha^w_t\)，当 \(\alpha^w_t > \eta\) 时生成候选记忆令牌 \(\gamma_t\) 并写入记忆库（超过预算时压缩）。写门使用预测的边界标签进行监督（BCE损失），读门通过稀疏正则化鼓励稀疏使用。

4. **训练流程**（三阶段）：
   - **Stage I**：学习低层分词器（使用光流 + 可选的行动标签）。
   - **Stage II**：冻结分词器，发现技能并预训练规划器和执行器（无外部记忆），损失包含技能MSE、隐动作块MSE、边界BCE。
   - **Stage III**：激活记忆模块，在行动标注的演示上微调整个策略，损失包括行动预测（MSE或负对数似然）、规划损失、执行损失、边界损失和门控损失（含稀疏正则）。

5. **推理**：完全因果，仅需当前RGB观测、本体感觉、指令和记忆库。无需生成未来视频或光流。

## 6. 主要结论与发现
1. **分层隐动作提升鲁棒性**：Stage II预训练（隐动作）在LIBERO标准设置下提升+1.1%，在LIBERO-PLUS零样本扰动下提升+3.8%，说明隐动作捕捉了可迁移的运动模式，减少过拟合。
2. **记忆门控模块显著改善记忆依赖任务**：在RMBench上平均成功率26.3%（M(1) 31.6%，M(n) 19.8%），优于DP、ACT、π0.5、X-VLA等。但在M(n)任务上仍低于Mem-0（后者使用8B规划器和更专门的记忆设计），说明更强的记忆推理仍有提升空间。
3. **真实世界泛化优势**：在Medium和Hard任务上优于π0.5（Hard任务ST提升+25%，GE提升+20%），证明记忆模块帮助维持任务状态，减少遗忘。
4. **隐动作预训练适用于多种动作表示**：无论使用关节位置还是末端执行器位姿，Stage II均带来明显提升，尤其对末端执行器位姿（含较少执行细节）受益更大。
