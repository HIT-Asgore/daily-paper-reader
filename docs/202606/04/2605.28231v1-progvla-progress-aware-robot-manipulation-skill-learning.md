## 摘要
我们提出了ProgVLA，一种紧凑的视觉-语言-动作（VLA）模型，设计用于在紧凑的计算和内存预算下实现可靠的机器人操作。该模型特别专注于通过维护任务在长时间跨度上的显式进度表示，高效地处理长多模态序列。为此，ProgVLA集成了两个关键组件。首先，一个具有两阶段感知器重采样方案的多模态编码器，将可变长度的视觉、语言和本体感受流压缩为一组固定的、可用于控制的上下文令牌，在保持跨模态基础的同时显著减少序列长度。其次，一组辅助的进度头通过离线强化学习（RL）目标进行训练，以联合学习关于归一化剩余时间范围的评判器。这为策略提供了任务进度的内部估计，并实现了基于优势和成功加权的流匹配模仿学习。在两个成熟的多任务机器人操作基准测试中，一个0.1B参数的ProgVLA模型达到了与更大规模预训练基线相竞争的成功率，并且在长视野和更困难的任务层级上超越了它们。消融实验表明，学习到的上下文重采样器和任务自适应视觉微调是最大的单独贡献因素，而进度感知训练则提供了持续的额外增益，主要集中在长视野和多对象任务上。我们还在真实的玩具厨房环境中进一步验证了该方法。

## Abstract
We present ProgVLA, a compact vision-language-action (VLA) model designed for reliable robot manipulation under tight compute and memory budgets. The model specifically focuses on efficiently processing long multi-modal sequences by maintaining an explicit representation of task progress over extended horizons. To this end, ProgVLA integrates two key components. First, a multi-modal encoder with a two-stage Perceiver resampling scheme compresses variable-length visual, language, and proprioceptive streams into a fixed set of control-ready context tokens, substantially reducing sequence length while preserving cross-modal grounding. Second, an auxiliary set of progress heads is trained with offline reinforcement learning (RL) objectives to jointly learn critics over normalized remaining-horizon targets. This provides the policy with an internal estimate of task progress and enables advantage- and success-weighted flow-matching imitation learning. On two well-established multi-task robot manipulation benchmarks, a 0.1B-parameter ProgVLA model reaches success rates that are competitive with, and on long-horizon and harder task tiers exceed, substantially larger pretrained baselines. Ablations indicate that the learned context resampler and task-adaptive visual fine-tuning are the largest single contributors, while progress-aware training provides a consistent additional gain that is concentrated on long-horizon and multi-object tasks. We further validate the approach in real-world toy-kitchen environments.

- **研究动机**：现有的视觉-语言-动作（VLA）模型（如 OpenVLA、π₀）往往依赖超大规模骨干网络和跨具身机器人预训练，参数达数十亿，推理成本高，难以在资源受限的设备上部署；而紧凑型 VLA（如 SmolVLA）虽然参数较少，但在长视野（long-horizon）任务上表现不佳。

- **整体含义**：通过两阶段感知器重采样（Perceiver Resampler）将多模态输入压缩为固定长度的上下文令牌，并引入基于离线强化学习目标的辅助进度头（progress heads），使模型内部能够估计任务进度，从而在长时域操作中实现更可靠的策略学习。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：ProgVLA 采用紧凑的 Transformer 架构，通过三个互补设计提升长时域操作能力：
  1. **高效跨模态特征提取**：两阶段感知器重采样（per-modality 与 post-fusion）将视觉、语言和本体感受流压缩成少量控制键令牌，大幅减少序列长度。
  2. **通用视觉骨干**：使用 DUNE（基于 ViT-Small 的通用编码器，从多种 2D/3D 任务蒸馏而来），并联合微调，以提供优于单源预训练的视觉先验。
  3. **显式时间感知**：通过辅助进度头（状态-动作批评器 ˆQ、状态值 ˆV、成功分类 ˆS）联合训练，从同一上下文令牌中回归归一化的剩余时域进度目标 rₜ = max(0, 1−(T−t)/T_M)，并利用产生的优势权重和成功概率权重重新加权流匹配模仿损失。

- **关键技术细节**：
  - **多模态编码器**：视觉 DUNE → 每模态 Perceiver Resampler（输出固定数量令牌）→ 共享融合 Transformer → 后融合 Perceiver Resampler → 4个上下文令牌。
  - **动作专家**：基于 SmolVLA 的流匹配（flow-matching）架构，训练时从 Beta(2,2) 采样时间 τ，使用 Heun 法推理 10 步，预测 16 步动作块，执行前 8 步。

  - **训练细节**：仅成功演示（无失败轨迹），所有进度头输出被截断梯度，仅用作损失权重；无策略梯度更新。

  - 进度目标：rₜ = max(0, 1 - (T - t) / 500)

### 6. 论文的主要结论与发现
- **主要结论**：一个 0.1B 参数的紧凑 VLA 模型，通过两阶段感知器重采样、通用视觉骨干微调和进度感知辅助训练，在不使用大规模机器人预训练的情况下，在 LIBERO 和 Meta-World 上达到或超过更大预训练模型的表现，尤其在长时域、多对象和高难度任务上优势显著。
- **关键发现**：
  - 后融合上下文重采样器是最大贡献因素（平均 SR 下降 16.0 点），移除后长时域任务 SR 从 88.6% 降至 51.2%。

  - 真实世界实验平均成功率 68%，三种主要失败模式：场景遮挡（10/32）、夹爪超时（8/32）、抓错物体（4/32）。

### 7. 优点
- **方法创新**：将离线 RL 中的价值学习（分位数回归、优势加权）巧妙地用作模仿学习的重加权信号，而非策略梯度；两阶段重采样设计分离了模态归一化和后融合压缩，实现高效上下文表示。
- **可部署性**：0.1B 参数、无跨具身预训练、真实实时运行在便携笔记本上，大大降低了 VLA 应用门槛。
- **实验验证全面**：覆盖两个主流模拟基准 + 真实机器人，包含充分的消融实验，逐组件分析贡献。
- **诚实处理基线**：明确说明基线为引用结果、存在协议差异，并分析了差异方向（图像分辨率不利于 ProgVLA，演示数有利），增强了可信度。
- **广泛讨论局限**：在附录中详细列出多项局限（进度目标为纯时间、未校准、单种子、未跨环境泛化等），为后续工作指明方向。
