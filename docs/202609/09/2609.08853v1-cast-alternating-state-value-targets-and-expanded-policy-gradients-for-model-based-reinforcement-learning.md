## 摘要
基于模型的强化学习（MBRL）是一类学习环境模型并将其用于动作选择的强化学习方法，因其样本效率高而特别适合机器人领域。将学习到的模型与在线规划结合可进一步提升动作选择质量，因为规划器能够利用模型找到比单独使用学习策略更优的动作。近期结合学习策略与在线规划的方法通常学习的是策略的价值，而非更强的规划器引导行为。我们提出CAST（带交替状态值目标的评论家），它利用规划器引导的行为来改进价值学习，同时用当前策略对价值估计进行正则化。CAST采用状态值评论家替代动作值评论家，其训练目标结合了真实的规划器引导转移和当前策略下的想象转移。由此得到的价值函数对应于规划器引导行为与当前策略之间的交替过程，从而既能受益于更强的规划器行为，又能受到正在学习的策略的正则化。我们在DeepMind Control和HumanoidBench套件上对CAST与多种最先进方法进行了评估，并展示了其成功迁移至执行动态倒立的实体宇树Go2四足机器人。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

## 1. 论文核心问题与整体含义（研究动机与背景）

强化学习（RL）在机器人复杂行为学习方面取得了显著进展，但在真实世界中应用仍面临样本复杂度高的核心瓶颈。基于模型的强化学习（MBRL）通过学习环境模型来减少真实环境交互所需样本量，使其特别适合机器人领域。

本文的核心观察与问题在于：

- 近年来，将**在线规划（MPPI）**与**显式学习策略**相结合已成为 MBRL 的主流范式（如 TD-MPC2、BMPC、BOOM 等），即通过规划器对学习策略进行“细化”，从而在每步选择优于策略本身的动作。
- 然而，现有方法普遍存在的问题是：**评论家（Critic）学习的是学习策略 πθ 本身的价值**，而非更强的规划器引导行为 β 的价值。尽管在训练过程中 β 通常远优于 πθ，但若直接将评论家对准 β 的价值会造成策略更新剧烈、训练不稳定。
- 作者的洞察是：评论家应当学习 **更强的规划器行为 β 的价值**（而非当前策略 πθ 的价值），以便为策略改进提供更优的信号；同时需要通过某种形式进行“正则化”以避免训练崩塌。

**核心含义**：传统方法被迫将策略拉向规划器（BOOM、BMPC），而 CAST 选择将评论家“推”向规划器，同时保持策略自身的稳定性——一个截然不同的切入视角。

## 2. 论文提出的方法论

### 2.1 总体框架

CAST 建立在 TD-MPC2 框架之上，保留其潜在世界模型（潜在编码器 hξ、动力学 dξ、奖励头 Rξ）和 MPPI 规划器，但进行了两项关键改造：

1. **将动作值评论家 Q(z, a) 替换为状态值评论家 V(z)**（集成 N=5 个 V 网络）；
2. **引入新的混合值目标（Hybrid Value Target）与扩展策略梯度（Expanded Policy Gradient）**。

整体工作流程为：MPPI 规划器使用状态值做终端评估 → 选择环境动作；经验回放数据由行为策略 β 产生；训练时评论家学习一个介于 β 和 πθ 之间的“交替过程”，策略则通过模型展开传播梯度进行优化。

### 2.2 状态值评论家与 Q 重建

由于 β 的动作分布只有重新运行规划器才能获得（代价极高），学习 Qβ 不现实；而 Vβ 仅依赖状态，可以直接从回放缓冲区中的状态学习。当需要动作值估计时，可用学习到的模型重建一步估计：

\[
\hat{Q}(z, a) = R_\xi(z, a) + \gamma \bar{V}_\psi\big(d_\xi(z, a)\big)
\]

规划器的终端价值也由式 (8) 给出，直接用状态值而非通过终端动作采样的 Q 值：

\[
\hat{G}(z_t, a_{t:t+H}) = \sum_{h=0}^{H-1} \gamma^h R_\xi(z_{t+h}, a_{t+h}) + \gamma^H \bar{V}_\psi(z_{t+H})
\]

### 2.3 混合贝尔曼目标（核心创新之一）

评论家的训练目标由**一步真实 β 转移**和**一步想象 πθ 转移**组合而成：

\[
y_t = r_t + \gamma\left[ R_\xi(z_{t+1}, \tilde{a}_{t+1}) + \gamma \bar{V}_\psi(\tilde{z}_{t+2}) \right], \quad \tilde{a}_{t+1} \sim \pi_\theta(\cdot|z_{t+1}),\ \tilde{z}_{t+2} = d_\xi(z_{t+1}, \tilde{a}_{t+1})
\]

**动机与效果**：真实一步将目标锚定在更强行为 β 上；想象一步则引入当前策略 πθ 进行正则，避免完全塌缩到 β 导致策略更新过于激进。

### 2.4 理论分析（交替过程的固定点）

文中证明了在固定策略、确定性动力学和可精确表示价值函数的假设下：

- 定义 Tβ 与 Tπ 分别为 β 与 πθ 的贝尔曼算子；
- CAST 目标对应复合算子 \(T_{CAST} = T_\beta \circ T_\pi\)；
- 该算子是 γ²-压缩映射，存在唯一不动点 VCAST；
- 展开该不动点等价于 β → πθ → β → πθ → … 无限交替过程的回报期望，因此 VCAST 介于 Vβ 与 Vπθ 之间。

### 2.5 扩展策略梯度（核心创新之二）

由于 V 不直接依赖动作输入，无法像 Q(z, πθ(z)) 那样对动作求梯度，CAST 提出通过在潜在世界模型中将策略展开 Hπ 步，再进行引导：

\[
J_k(z_0; \theta) = \sum_{i=0}^{H_\pi - 1} \gamma^i R_\xi(z^{(i)}, a^{(i)}) + \gamma^{H_\pi} \bar{V}_\psi(z^{(H_\pi)})
\]

梯度流经整个想象链 πθ → Rξ → dξ → ⋯ → V̄ψ。默认配置采用 Hπ=1（研究 Hπ>1 的消融）。

### 2.6 训练流程

核心改动集中在：
- 价值目标变为混合目标（真实 β 一步 + 想象 πθ 一步）；
- 策略优化变为通过模型展开传播梯度（扩展策略梯度）；
- 规划器终值用状态值替代动作值。

## 6. 论文主要结论与发现

1. **在 1M 步时**，CAST（平均 764 分）显著优于所有基线——超过 BMPC（644）、BOOM（721）、TD-MPC2（340），证明其样本效率优势；
2. **在 2M 步时**，CAST（平均 839）与 BOOM（849）持平，明显优于 BMPC（691）和 TD-MPC2（535），说明其最终性能有竞争力但已无显著领先；
3. **AUC 性能曲线**显示 CAST 在 14 个任务整体上具有最佳表现，尤其在 HumanoidBench 上显著占优；
4. 纯 off-policy 目标效果最差，证实“直接引导 β 会导致不稳定”的核心假设；混合目标比纯 on-policy 目标更好；
5. **HV=1 和 Hπ=1** 分别证实“一步 β + 一步 πθ”及“一步展开策略梯度”是最优配置；
6. CAST 训练的策略能够成功迁移到真实 Unitree Go2 上完成动态倒立，证明其具有 sim-to-real 可行性。

## 7. 优点

1. **创新性问题定义**：首次从“评论家应学习规划器 β 而非策略 πθ 价值”这一角度入手，与既有“将策略拉向规划器”的研究方向截然不同；
2. **理论严谨**：对混合贝尔曼算子的压缩性、唯一不动点、交替过程展开等给出了清晰的形式化刻画；
3. **学习 V 而非 Q 的巧妙设计**：从 β 的动作分布获取成本高的痛点出发，论证了状态值函数是学习 β 价值的正确选择，还顺带免去规划器终值处的策略动作采样，减少推理开销；
4. **混合目标思想优雅**：用“一步真实 β + 一步虚拟 πθ”在“更强价值信号”与“策略正则化”间自然折中，理论证明其不动点有明确的交替形态；

6. **真实机器人验证**：提供硬实力证据，证明方法在实际系统中可行，而不只是仿真玩具。

## 8. 不足与局限

1. **消融实验的代表性担忧**：关键消融只在 Dog-run 和 Humanoid-run 两个任务上进行；在样本效率差异已见显著的任务上（如 H1hand-run），未验证各组件在更广任务集中的消融效果是否一致；
2. **训练方差较大**：部分曲线（如 H1hand-run 1M 处的收益 570±379）置信区间大，说明方法在该类任务上的稳定性有待改进，可能影响实际使用信心；
3. **最终性能无显著优势**：2M 步后 CAST 与 BOOM 持平，并未在所有任务上占据最终最优地位（如 2M 步的 average 839 vs BOOM 849），其宣称的“改进”主要体现在中前期（1M 步）的样本效率上；

5. **缺乏跨硬件部署的泛化证据**：仅展示了单一机器人单一任务的 sim-to-real 实验，未对失败率、鲁棒性等做定量分析，也未在更多硬件上验证；
