## 摘要
基于视觉的人形机器人全身移动操作因部分可观测性、接触丰富的动力学以及从高维视觉输入中学习长时域行为的困难而具有挑战性。我们提出了 DreamMimic，一个通过世界模型辅助蒸馏将特权教师策略蒸馏为基于视觉的人形控制器的框架。我们并非使用 Dreamer 风格的 RSSM 进行规划，而是将其重新用于学习预测性潜在动力学，该动力学既作为表示空间，又作为动作条件下的多步监督信号，同时向学生策略暴露紧凑的预测特征以减少长期漂移。除了对本体感觉和视觉观测的标准重建目标外，我们还为特权状态、接触、物体状态和奖励估计添加了辅助预测头。这些预测头提供了与智能体-物体交互和任务进展相关的额外监督，鼓励潜在表示保留对接触丰富的移动操作有用的信号。我们进一步引入了性能条件引导（PCG），一种奖励驱动的自适应蒸馏调度，计算教师和学生的性能分数以动态平衡引导和探索。PCG 在具有挑战性的视觉环境中既防止了过早的教师退火，也防止了过度的教师干扰。在 OMOMO 和 BEHAVE 上的实验表明，与强基于视觉的基线相比，跟踪式移动操作性能得到提升，而无需在部署时向学生暴露在线的特权交互状态。定性仿真进一步检验了形态和模拟器变化。这些结果表明，世界模型可以为接触丰富的人形行为中的视觉策略蒸馏稳定性提供一种有用的机制。

## Abstract
Vision-based whole-body loco-manipulation on humanoid robots is challenging due to partial observability, contact-rich dynamics, and the difficulty of learning long-horizon behaviors from high-dimensional visual inputs. We present \href{https://github.com/DreamMimic/DreamMimic}{DreamMimic}, a framework that distills privileged teacher policies into vision-based humanoid controllers via world-model-assisted distillation. Instead of using a Dreamer-style RSSM for planning, we repurpose it to learn predictive latent dynamics that serve as both a representation space and an action-conditioned multi-step supervision signal, while exposing compact predictive features to the student policy to reduce long-term drift. Beyond standard reconstruction objectives for proprioceptive and visual observations, we add auxiliary prediction heads for privileged state, contact, object state, and reward estimation. These heads provide additional supervision related to agent--object interaction and task progress, encouraging the latent representation to retain signals that are useful for contact-rich loco-manipulation. We further introduce Performance-Conditioned Guidance (PCG), a reward-driven adaptive distillation schedule that computes performance scores for both teacher and student to dynamically balance guidance and exploration. PCG prevents both premature teacher annealing and excessive teacher interference in challenging visual settings. Experiments on OMOMO and BEHAVE show improved tracking-based loco-manipulation performance over strong vision-based baselines, without exposing online privileged interaction states to the student at deployment. Qualitative simulations further examine morphology and simulator changes. These results suggest that world models can provide a useful mechanism for stabilizing visual policy distillation in contact-rich humanoid behaviors.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 人形机器人在工厂自动化和日常辅助中需执行全身移动操作（whole-body loco-manipulation），即在视觉反馈下协调全身运动与物体交互。
- 这类任务面临三重核心挑战：
  - **部分可观测性**（partial observability）：部署时无法获取仿真器中的特权信息（如真实物体位姿、接触状态、交互图）；
  - **接触丰富的动力学**（contact-rich dynamics）：接触不连续、时序耦合，对控制精度要求极高；
  - **高维视觉输入下的长时域学习**：从像素直接学习长时间跨度的策略易出现复合误差。
- 已有工作存在明显缺陷：有的仅聚焦于运动而不涉及复杂物体交互；有的依赖特权信息或预计算状态估计器，无法直接部署；部分视觉运动学习框架缺乏预测性的时序结构化表征，难以应对长时域接触任务。
- DreamMimic 的核心动机是：利用世界模型（world model）学习预测性潜在动力学，作为蒸馏过程中的表征空间与多步监督信号，从而在不依靠在线特权信息的前提下，稳定地完成从特权教师策略到视觉学生策略的蒸馏。

## 2. 方法论

**核心思想：** 将 Dreamer-style RSSM（循环状态空间模型）从“规划器”重新定位为“预测性表征学习器”，同时充当表征空间和动作条件下的多步监督信号，向学生策略暴露紧凑的预测性交互特征以减少长期漂移。

**关键技术细节：**

1. **特权教师策略（Privileged Teacher Policy）**：教师策略可访问全部仿真状态（真实物体位姿、交互图、接触信号），通过强化学习（RL）跟踪参考运动并整合全身跟踪、末端对齐、物体一致性和接触感知奖励，学习稳定的接触丰富行为。遵循 InterMimic 的“专家到通才”范式，用多个专家任务构建统一的导师模型。

2. **视觉学生蒸馏（Visuomotor Student Distillation）**：
   - 学生策略输入条件为：
     ```
     c_t = [p_t, g_t, φ_wm_t]
     a_t ~ πθ(· | c_t)
     ```
   其中 `p_t` 是非特权本体感觉，`g_t` 是紧凑目标条件（目标物体位姿 + 短时机器人轨迹线索），`φ_wm_t` 是世界模型特征。
   - 世界模型特征：
     ```
     φ_wm_t = [h_t, r̂_t, x̂_priv_t, ĉ_contact_t, x̂_obj_t]
     ```
   即确定性 RSSM 状态、奖励预测、特权状态预测、接触预测、物体状态预测。
   - 策略网络将本体感觉-目标特征、确定性世界模型特征、辅助预测特征分别作为 token，通过轻量级 Transformer 融合后再接 actor-critic MLP。
   - 训练以监督模仿（action distillation）为主要学习信号，PPO 作为辅助稳定器。

3. **PCG（Performance-Conditioned Guidance）**：
   - 通过环境角色指示符 `m ∈ {0,1}` 分配教师驱动或学生驱动 rollout；
   - 维护教师/学生环境的指数移动平均奖励 `r̂T` 和 `r̂S`，计算相对性能分数 `π = r̂S/(r̂T + ε)`；
   - 当 `π` 接近目标性能比时，将教师环境比例 `ρ` 从 `ρ_max` 衰减到 `ρ_min`，但保持模仿监督系数固定；
   - 目的：防止过早的教师退火（学生未成熟时失去指导）和过度的教师干扰（学生已胜任但教师仍主导状态分布）。

4. **参考缓冲区课程（Reference-buffer curriculum）**：
   - 基于 InterMimic 风格，从失败的学生驱动 rollouts 中更新一小部分重放参考状态，使后续训练能回访困难交互状态。

5. **世界模型（RSSM）**：
   - 编码器 `Eξ` 处理视觉输入（深度+分割）和本体感觉；
   - 确定性转移函数 `fξ`（GRU）更新循环状态 `h_t`，后验 `qξ` 推断随机状态 `s_t`；
   - 同时定义先验 `pξ` 用于开环预测；
   - 解码器 `Dξ` 做视觉/本体感觉重建；辅助预测头输出奖励、特权状态、接触和物体状态；
   - 重建输出仅供表征学习使用，不直接喂给策略。

6. **多步潜在蒸馏（Multi-step Latent Distillation）**：
   - 从当前后验潜在状态 `z_t` 出发，冻结世界模型参数，分别以学生策略动作均值 `μ^S_t` 和教师策略动作均值 `μ^T_t` 做 H=3 步先验 rollout，最小化：
     ```
     L_latent = Σ_{k=1}^{H} [ ||h^S_{t+k} - h^T_{t+k}||²₂ + λ_stoch ||s^S_{t+k} - s^T_{t+k}||²₂ ]
     ```
   - 此损失无需教师侧视觉观测，纯粹利用学习到的动力学作为动作条件下师生策略均值的局部一致性度量。

7. **整体训练目标**：
   - 世界模型损失：
     ```
     L_wm = L_KL + L_rec + L_rew + L_priv + L_con + L_obj
     ```
   - 学生策略总损失：
     ```
     L_total = c·w_action·L_action + w_wm·L_latent + w_ppo·L_ppo
     ```
   - 世界模型与策略分离优化：世界模型周期性从重放序列更新，避免策略与表征目标同时漂移。

## 6. 论文的主要结论与发现

- **世界模型能显著稳定视觉策略蒸馏**：DreamMimic 在 OMOMO 上达到 92.2% 成功率、184.18 步平均持续时长，远优于直接 RL-from-pixels（0%）和普通视觉编码器 + DAgger+RL（72.6%）。
- **多步潜在蒸馏是关键组件**：去掉后成功率从 92.2% 降至 70.6%，说明单步动作匹配不足以约束接触丰富场景下的未来状态演化。
- **辅助交互预测头有效降低物体跟踪误差**：物体状态预测能将 OMOMO 物体误差从 12.7cm 降至 10.0cm，完整模型进一步降至 8.8cm。
- **预测性特征作为策略输入比仅作损失更有用**：将辅助头仅作为损失而不喂给策略时，成功率降至 84.3%。
- **循环确定性状态（recurrent deterministic state）是最核心的时序组件**：去除后成功率降至 88.2%；仅用当前步随机特征则骤降至 74.5%。
- **PCG 优于基于迭代的朴素退火**：在 BEHAVE 上二者成功率相同（72.7%），但 PCG 的跟踪误差更低（Er 10.2 vs 15.2）且持续时间更长（289.53 vs 275.21 步），且减少了对人工调节退火计划的依赖。
- **深度+分割是最佳视觉模态组合**（92.2% 成功率），高于分割-only（86.3%）、深度-only（88.2%）和 RGB（88.2%）。

## 7. 优点

- **方法创新性强**：
  - 将 Dreamer 式世界模型从“规划器”重构为“蒸馏稳定器”，定位独特；
  - 多步动作条件下的潜在一致性损失（multi-step latent consistency）是处理部分可观测接触任务的新机制；
  - PCG 基于奖励反馈自适应调节师生 rollout 比例，比传统迭代退火更鲁棒、更少人工干预；
  - 辅助预测头设计（特权状态/接触/物体状态/奖励）为目标条件策略注入了交互相关的归纳偏置，同时部署时无需在线特权信号。
- **实验设计较为扎实**：
  - 两个数据集 + 增重压力测试 + 多种基线 + 6 组消融 + 跨体态/跨仿真器定性验证，证据链完整；
  - 消融实验采用递进式设计，能清晰分离每个组件的贡献。
- **工程实现完整**：提供项目页面和代码链接（github.com/DreamMimic/DreamMimic），有利于复现和后续研究。
- **实际部署友好**：学生策略在部署时仅依赖非特权本体感觉、紧凑目标条件和世界模型预测特征，不暴露在线特权状态。

- **算力细节缺失**：未报告 GPU 型号/数量、训练时间等，复现成本不透明。
- **统计严谨性不足**：结果未报告多次随机种子下的方差或显著性检验，部分消融差距较小（如 x5 增重下成功率仅差 2%），结论稳健性需谨慎对待。
- **失败案例分析揭示的局限**：
  - 严重遮挡或视觉模糊的接触场景仍会出错；

- **世界模型的感知输入依赖**：仿真渲染的深度/分割与实际传感器模态存在差距，作者也承认这点并认为需要更鲁棒的感知、触觉或局部手-物控制以及遮挡下的恢复行为来弥补。
