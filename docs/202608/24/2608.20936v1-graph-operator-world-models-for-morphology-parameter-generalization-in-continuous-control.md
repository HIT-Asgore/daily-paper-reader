## 摘要
用于连续控制的世界模型通常针对固定物理系统进行训练，当已知的形态参数如连杆长度、质量、阻尼和驱动发生变化时，其性能可能会下降。现有方法通常将这些参数作为条件信息提供，但未明确学到的转移中哪些部分应保持可复用，哪些部分应随形态变化。我们提出了图算子世界模型（GraphOp-WM），一种结构化世界模型，用于在相关铰接机器人家族中跨未见形态参数进行泛化。GraphOp-WM将刚体及其运动学关系表示为属性图，并将每个转移分解为与形态无关的局部动力学基和一个由形态条件化的结构化算子。该算子结合了节点局部调制、运动学树耦合和低秩全局校正，同时架构信息分离、基归一化和成对形态监督鼓励静态形态依赖性由算子路径承载。图级读出和逐边动作表示为奖励、价值和TD-MPC式规划提供了兼容的接口。我们进一步定义了受控的MuJoCo参数划分，涵盖Hopper、Walker2d和HalfCheetah中连杆几何、质量、阻尼和驱动参数的插值、外推和保留组合。

## Abstract
World models for continuous control are commonly trained for a fixed physical system and can degrade when known morphology parameters such as link lengths, masses, damping, and actuation change. Existing approaches often provide these parameters as conditioning information, but leave unspecified which part of the learned transition should remain reusable and which part should change with morphology. We propose Graph-Operator World Models (GraphOp-WM), a structured world model for generalization across unseen morphology parameters within related articulated robot families. GraphOp-WM represents bodies and their kinematic relations as an attributed graph and factorizes each transition into a morphology-independent local dynamics basis and a morphology-conditioned structured operator. The operator combines node-local modulation, kinematic-tree coupling, and a low-rank global correction, while architectural information separation, basis normalization, and paired-morphology supervision encourage static morphology dependence to be carried by the operator pathway. Graph-level readout and edge-wise action representations provide a compatible interface for reward, value, and TD-MPC-style planning. We further define controlled MuJoCo parameter splits covering interpolation, extrapolation, and held-out compositions of link geometry, mass, damping, and actuation parameters in Hopper, Walker2d, and HalfCheetah.

## 2. 论文提出的方法论：核心思想、技术细节与算法流程

### 核心思想

论文提出 **GraphOp-WM（Graph-Operator World Models）**，一种图结构世界模型。其核心是将机器人表示为属性图，并将状态转移分解为两个部分：

1. **形态无关的局部动力学基（Morphology-Independent Local Dynamics Basis）**：用共享的局部核预测每个刚体的"规范增量"，只依赖局部动态状态、局部动作与离散刚体类型，**无法观测**质量、长度、惯性、形态标识符或全局形态嵌入。
2. **形态条件化的结构化算子（Morphology-Conditioned Structured Operator）**：由形态编码器从 MuJoCo 形态图生成，作用于共享局部增量上，从而决定这些局部响应如何传播和耦合。

### 状态转移公式

对于刚体 token 矩阵 \(Z_t \in \mathbb{R}^{N_m \times d}\)，预测转移为：
\[
\hat{Z}_{t+1} = Z_t + A_{m,t} \bar{B}_t
\]
其中 \(\bar{B}_t\) 是归一化后的共享局部动力学基，\(A_{m,t}\) 是形态参数条件化的图算子。

### 结构化算子形式

\[
A_{m,t} = I + \text{Diag}(d_{m,t}) + E_m \text{Diag}(w_{m,t}) E_m^\top + U_{m,t} \text{Diag}(s_{m,t}) U_{m,t}^\top
\]

四个组成项分别编码四种归纳偏置：
- **单位阵 I**：保持恒等残差连接；
- **对角项 \(\text{Diag}(d_{m,t})\)**：捕获刚体局部响应调制；
- **关联矩阵项 \(E_m \text{Diag}(w_{m,t}) E_m^\top\)**：沿运动学树进行图耦合传播；
- **低秩项 \(U_{m,t} \text{Diag}(s_{m,t}) U_{m,t}^\top\)**：捕获躯干-肢体耦合和接触介导的全局残差模态。

### 关键技术细节

- **信息分离（Information Separation）**：静态形态属性只进入算子 \(A_{m,t}\)，局部基只观测动态局部状态和动作——从架构上强制了角色分工；
- **基归一化（Basis Normalization）**：按每个图的根均方（RMS）幅度归一化 \(\bar{B}_t\)，消除基与算子之间的任意尺度模糊性；
- **成对形态监督（Paired-Morphology Supervision）**：对同一归一化初始姿态、同一动作序列下的两个形态变体，共享局部基但使用各自算子，通过成对损失监督形态依赖的转移差异，确保形态相关的变化被分配到算子路径上；
- **图级读出与逐边动作表示**：用全局查询注意力获得固定维度的图级表示，动作挂载在驱动器边上，使奖励、价值和规划接口兼容不同刚体/执行器数量的形态。

### 训练目标

总损失包含：
\[
\mathcal{L} = \mathcal{L}_{\text{dyn}} + \lambda_r \mathcal{L}_r + \lambda_Q \mathcal{L}_Q + \lambda_V \mathcal{L}_V + \lambda_{\text{pair}} \mathcal{L}_{\text{pair}} + \lambda_{\text{op}} \mathcal{L}_{\text{op}}
\]
其中包含动力学损失、奖励损失、Q 值损失、TD 值损失、成对形态损失和算子正则化损失。

### 控制接口（TD-MPC 风格规划）

在决策时，MPC 对所有候选轨迹基于当前形态的节点数和执行器数采样动作张量（维度随形态变化），不同形态在各自的规划调用中实例化不同的动作张量，无需全局最大动作维度。

### 环境家族与基准定义

- **机器人家族**：MuJoCo 物理引擎下的三个标准连续控制任务——**Hopper、Walker2d、HalfCheetah**。
- **形态参数维度**：连杆长度、连杆质量、躯干质量、关节阻尼、驱动器齿轮比（actuator gear），共五类形态属性；刚体惯性由几何和质量变化后重新计算，不独立变化。
- **形态图构建**：将每个规范 MJCF 模型转换为属性图——刚体为节点（含几何、惯性、接触、坐标系等静态属性），关节为边（含关节类型、轴、原点、范围、阻尼、齿轮比等），执行器关联到受控关节。
- **四类划分**：
  - **训练包络（Training envelope）**：各参数乘性因子在合理范围（如连杆长度 [0.80, 1.20]）内，用最大化拉丁超立方采样生成训练形态；
  - **插值集（Interpolation）**：训练包络内的未见参数值和组合；
  - **外推集（Extrapolation）**：超出训练包络的参数值（如连杆长度 [0.60, 0.75] ∪ [1.25, 1.40]）；
  - **保留组合集（Held-out composition）**：单个维度已在训练中见过、但它们的联合组合未见过的形态（如远端连杆长度 1.25 与执行器齿轮比 0.70 的组合）。

## 6. 论文的主要结论与发现

- **结构化算子分解是有效的归纳偏置**：将状态转移分解为形态无关的局部基和形态条件化的结构化算子，比把形态参数压成单一上下文向量更具结构性。
- **信息分离能够实现角色分工**：通过架构约束使形态依赖由算子承载、局部动力学由共享基承载，避免了形态信息被"吸收"进共享表征的歧义。
- **可变图接口支持跨形态规划**：节点级状态和边级动作表示使得同一种 TD-MPC 式规划逻辑可以适配不同刚体数/执行器数的形态。
- **成对形态监督强化了分解的语义一致性**：通过共享基+双算子的监督方式，迫使算子之间编码形态差异。
- **基准设计覆盖了多种 OOD 场景**：插值、外推和保留组合三维度的划分，能够系统性度量参数化模型在分布外预测与规划上的泛化能力。
