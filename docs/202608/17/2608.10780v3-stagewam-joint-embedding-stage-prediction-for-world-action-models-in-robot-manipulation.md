## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射到跨多样任务的动作上。然而，现有方法通常将未来表示为固定的、短期的视频-动作块。这种短期未来捕捉局部场景演化以用于动作执行，但它并未明确描述阶段级未来，即任务应如何从当前阶段推进到下一阶段。因此，我们区分了机器人操作的两种互补未来：用于捕捉局部场景演化的短期物理未来和用于表示任务进展的阶段级语义未来。我们引入了StageWAM，它用Stage-JEPA（一种目标条件联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一个推断阶段的潜在目标。在清洁和随机环境中的50个RoboTwin 2.0任务中，StageWAM实现了90.25%的总体成功率，并将成功轨迹中的平均执行步数相对最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce StageWAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, StageWAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 通用机器人策略（Generalist Policies）的核心目标是将多模态观测（视觉、机器人状态）和语言任务指令映射为可执行动作。
- 现有方法分为两类，均存在明显不足：
  - **Vision-Language-Action Models（VLAs）**：如 RT-2、OpenVLA、π0.5 等，采用"观测→动作"的直接映射，未显式建模环境如何随任务推进而变化。
  - **World Action Models（WAMs）**：如 UWM、Motus 等，通过联合预测短时未来视频与动作来提供密集监督，但仅覆盖固定时间窗口的局部物理演化，**将任务进展隐含在稠密时间序列中，未显式说明下一个有意义的任务状态是什么**。
- 论文核心洞察：机器人操作中应区分**两种互补的未来**——
  - **短期物理未来（Short-term Physical Future）**：捕捉局部场景演化（物体运动、接触、局部视觉变化）。
  - **阶段级语义未来（Stage-level Semantic Future）**：描述任务进展，即"下一个应达到的物体状态或关系状态"（如空间对齐、抓取完成、容器放置等）。
- 现有方法（包括改进的 WAM 变体）均未显式建模阶段级未来，导致策略在长程任务中缺乏中间目标引导，容易产生冗余修正动作。

## 2. 论文提出的方法论

**核心思想：**

将阶段级语义未来建模为**表示空间中的预测目标**（而非像素级未来图像），并通过目标条件 JEPA 预测器——Stage-JEPA 来估计下一阶段潜表示，然后将其作为内部条件注入短期世界动作模型中，引导局部视频预测与动作生成。

**总体框架（两阶段训练）：**

StageWAM 包含两个顺序训练阶段，阶段 I 训练 JEPA 预测器，阶段 II 冻结预测器并训练条件化 WAM。

**(a) Stage I：训练 JEPA 预测器**

- **阶段对构建（Stage-pair construction）**：
  - 无需人工阶段标注，使用冻结 V-JEPA2 提取每 8 帧采样的 64 帧片段特征。
  - 通过局部窗口内表示变化评分（clip 级 L2 距离与 token 级最大 L2 距离的归一化最大值）检测关键转换帧，并用时间 NMS（r=3，K≤5）筛选，结合首尾帧构成阶段边界序列 B=(b₀,…,b_L)。
  - 每个阶段区间 [bᵢ, bᵢ₊₁) 内的每一帧 t 与下一个边界 bᵢ₊₁ 形成稠密的 (t, bᵢ₊₁) 监督对。
- **目标条件阶段预测（Goal-conditioned stage prediction）**：
  - 使用冻结 V-JEPA2 编码器分别编码以 t 和 bᵢ₊₁ 为中心的 64 帧观测切片，得到当前潜表示 z_t 与目标潜表示 z_target。
  - 可训练的 V-JEPA2 预测器（结合任务指令交叉注意力适配器）从当前切片与语言指令预测下一阶段 token 级表示，经池化与归一化得到 bẑ_target。
  - 损失函数为余弦对齐损失：
    \[
    \mathcal{L}_{\text{stage}} = \frac{1}{B} \sum_{i=1}^{B} \left(1 - (\hat{z}^{\text{target}}_i)^\top z^{\text{target}}_i\right)
    \]
  - 仅优化预测器与指令适配器，编码器完全冻结。

**(b) Stage II：训练阶段条件化 WAM**

- 以 Motus（Mixture-of-Transformers 架构，含视频生成专家、动作专家、视觉-语言理解专家）为底座，模型冻结 Stage-JEPA，仅训练 WAM 与条件注入接口。
- **门控注入机制**：将 Stage-JEPA 输出的 256 个预测 token 进行均值池化，经 MLP P_ψ 映射到 Wan 视频 token 维度，得到条件向量 h_t；通过全局标量门控 α=0.2σ(β) 控制注入强度：
  \[
  h_t = P_\psi(\text{Pool}(\hat{Z}^{\text{target}}_t)), \quad \alpha = 0.2\sigma(\beta), \quad \tilde{X}^{vt} = X^{vt} + \alpha h_t
  \]
- 训练损失为原生视频损失 + 动作损失 + 正则项：
  \[
  \mathcal{L} = \mathcal{L}_{\text{video}} + \mathcal{L}_{\text{action}} + \lambda_g \alpha^2 + \lambda_\rho (\rho - \rho_0)^2, \quad \rho = \frac{\|\alpha h_t\|}{\|X^{vt}\|}
  \]
  第一个正则项将门控偏向小残差更新，第二个确保注入阶段特征的相对幅度接近目标比值 ρ₀=0.08。

**(c) 闭环推理**

- 维持因果 64 帧观测缓冲区，使用冻结 Stage-JEPA 从当前观测历史与指令预测 bẑ_target，再通过 WAM 生成短时未来视频与动作块，以滚动时域方式执行。

## 6. 论文的主要结论与发现

1. **性能提升显著**：StageWAM 在 50 个 RoboTwin 2.0 任务上实现 **90.25% 总体成功率**（清洁 91.42%，随机 89.08%），超出最强基线 Motus（88.66%/87.02%）。
2. **类别差异明显**：在手势交互、目标放置、容器装填等依赖显式任务进展变化的类别上提升最大；在获取举升（依赖即时抓取几何）和关节交互（依赖机制特定接触）上优势较小甚至略逊于 Motus。
3. **消融结果**：移除 JEPA 部件导致最大性能下降（约 3%），验证阶段条件路径的必要性；直接向视频 token 注入未来潜在比仅用于当前帧表示更有效；阶段 I 目标训练提供额外但相对较小的增益；门控正则有助于稳定残差更新。
4. **执行效率提升**：成功轨迹平均长度从 79.57 步降至 74.82 步（**降低 5.97%**），所有 rollout 平均长度降低 15.02%，说明阶段引导可减少冗余纠正运动。
5. **阶段指导价值**：预测的下一阶段潜表示可作为内部进展目标，为局部动作生成提供任务进展偏差，避免反复上下移动等无效修正。

## 7. 优点

- **概念创新清晰**：首次明确提出"短期物理未来"与"阶段级语义未来"的区分，为机器人未来建模提供了新的理论框架。
- **方法论合理**：采用 JEPA 在表示空间（而非像素空间）预测阶段目标，避免像素预测侧重外观而忽略任务完成的缺陷，符合语义阶段的目标。
- **无人工标注**：阶段边界通过 V-JEPA2 特征变化自动推断，无需人工语义标注，可扩展性强。
- **双阶段设计**：先学习阶段语义，再学习局部实现，避免联合训练中细节损失干扰语义目标；冻结 JEPA 保证两阶段角色分离。
- **门控注入设计精巧**：全局标量门控 + 幅度正则，以最小参数量实现稳定的阶段条件注入，且可迁移至其他 WAM。
- **实验框架完整**：仿真大规模评测 + 消融 + 效率分析 + 真实机器人验证，结论多维度支撑。
- **代码与数据透明**：提供阶段监督诊断统计，便于复现与理解监督信号质量。

## 8. 不足与局限

- **实验覆盖有限**：仅验证单一仿真基准（RoboTwin 2.0）与单一 WAM 底座（Motus）；未在更多样化的操作基准（如 RLbench、LIBERO）或不同 WAM 架构上测试，泛化性证据不足。
- **真实评估薄弱**：仅 2 个任务、每任务 20 回合，且评分标准较粗（0/30/60/100 分档），无法捕捉执行过程中的细微质量差异。
- **阶段检测启发式**：V-JEPA2 特征变化评分 + NMS 的阶段自动构建可能存在噪声，尤其对无显著视觉突变的语义阶段（如"保持稳定"）可能失效；论文仅报告了统计诊断，未分析阶段检测错误对最终性能的影响。
- **注入机制简单**：全局标量门控对所有样本、层、token 统一，未利用空间/时间特异性；对需要精确接触与机制交互的任务（关节交互、工具使用）

- **注入机制简单**（续）：全局标量门控对所有样本、层、token 统一，未利用空间/时间特异性；对需要精确接触与机制交互的任务（关节交互、工具使用），这种粗粒度注入可能不足以提供细粒度的几何或力觉引导，这与实验中“关节交互类任务优势较小”的观察一致。未来可在 token 级或注意力层内实现条件注入，以增强对局部几何变化的响应能力。

- **阶段预测的可解释性与诊断不足**：论文未分析预测的阶段潜表示在语义上究竟对应何种实体状态（如“对齐”“插入”“放置到位”），也未展示阶段预测失败时的错误模式及其对闭环策略的级联影响。阶段检测错误如何传导到动作执行，仍是一个未打开的“黑箱”。

- **任务复杂度覆盖有限**：RoboTwin 2.0 的 50 个任务虽类型多样，但大多为单次阶段转换的短程操作（单次抓取、放置、按压），缺乏多阶段、顺序依赖的复杂任务（如“先挪开障碍→抓取→放入容器→按下开关”），而恰恰是这类任务最能体现阶段级未来建模的价值。

- **语言指令的利用较弱**：Stage-JEPA 对指令仅使用交叉注意力适配器，未显式约束阶段预测结果与指令语义一致；若指令存在多义或含糊表达，预测的阶段边界可能偏离用户真实意图。

- **与显式规划的对比缺失**：论文未与分层方法（如 LLM 驱动的子目标规划 + 低级策略）对比，因此无法判断“隐式阶段条件化”相比“显式阶段规划”的优势与劣势，削弱了方法定位的说服力。

## 9. 总结与综合评价

StageWAM 提出并验证了一个重要观点：在机器人操作中，除了建模短时物理演化，还应显式预测“下一个语义阶段”并以此引导动作生成。其方法在技术路径上具有较高创新性——将 JEPA 从“视频表示学习器”扩展为“阶段级未来预测器”，并借助门控机制将阶段条件注入世界动作模型，训练过程无需额外人工标注。

从证据角度看，论文具备**中等偏强**的实证支撑：大规模仿真评测、合理的消融设计、效率分析以及真实机器人试点，共同构成了较为完整的论证链。但受限于单一仿真基准、单一 WAM 底座、基线结果非本地重跑以及真实实验样本量偏小，结论的普遍性和统计稳健性仍有提升空间。

总体而言，这是一篇**概念清晰、方法有新意、实验框架规范**的工作，其“阶段级未来”的思想对后续机器人世界模型研究具有启发性。若能在更多基准、更多任务类型以及更精细的检测与注入机制上继续打磨，该框架有望成为通用机器人策略中任务进度建模的强有力组件。
