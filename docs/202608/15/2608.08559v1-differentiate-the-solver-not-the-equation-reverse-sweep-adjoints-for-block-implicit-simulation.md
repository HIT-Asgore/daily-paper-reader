## 摘要
可微仿真是学习、控制和反问题中的关键组成部分，其中需要非线性隐式求解器的梯度。现有方法要么依赖展开的自动微分，其内存随求解器深度增长；要么依赖方程级隐式微分，装配全局雅可比矩阵并求解大型稀疏伴随系统，丢弃了前向求解器的局部性——并且对收敛方程而非实际运行的有限计算进行微分。我们提出求解器级微分，对执行的求解器本身进行微分。当求解器由块隐式更新组成时，其离散伴随通过按逆序应用相应的伴随更新获得，产生反向扫描公式，其反向传播镜像前向求解器。从算子角度看，前向传播通过有序局部求解实现近似逆，反向通过反向局部伴随求解应用其转置，无需构建全局系统。我们将此思想实例化到顶点块下降上，得到一个可微求解器，其反向着色高斯-赛德尔扫描完全由局部$3\times 3$伴随求解组成。反向传播与通过相同执行前向的自动微分在机器精度水平上匹配，且在每个求解器深度均如此；而方程级伴随在一次扫描后偏差达37%；在受控的同类代码库、同类GPU比较中，它比展开自动微分快33倍，内存使用少71倍；同样的构造在投影动力学和扩展位置动力学上精确成立。我们将可微弹性动力学扩展到单GPU上$10^6$个接触耦合软体（8M顶点）。总体而言，本工作强调求解器结构作为高效可微仿真的实用组织原则。

## Abstract
Differentiable simulation is a key component in learning, control, and inverse problems, where gradients through nonlinear implicit solvers are required. Existing approaches either rely on unrolled automatic differentiation, whose memory grows with solver depth, or on equation-level implicit differentiation, which assembles global Jacobians and solves large sparse adjoint systems, discarding the locality of the forward solver -- and differentiating the converged equation rather than the finite computation that actually ran. We propose solver-level differentiation, which differentiates the executed solver itself. When a solver is composed of block implicit updates, its discrete adjoint is obtained by applying the corresponding adjoint updates in reverse order, yielding a reverse-sweep formulation whose backward pass mirrors the forward solver. From an operator perspective, the forward pass realizes an approximate inverse through ordered local solves, and the backward applies its transpose through reverse local adjoint solves, constructing no global system. We instantiate this idea on Vertex Block Descent, yielding a differentiable solver whose reverse colored Gauss-Seidel sweeps are composed entirely of local $3\times 3$ adjoint solves. The backward matches automatic differentiation through the identical executed forward to machine precision at every solver depth, where the equation-level adjoint is off by 37% after one sweep; in a controlled same-codebase, same-GPU comparison it is 33x faster and uses 71x less memory than unrolled automatic differentiation; and the same construction is exact on projective dynamics and extended position-based dynamics. We scale differentiable elastodynamics to $10^6$ contact-coupled soft bodies (8M vertices) on one GPU. Overall, this work highlights solver structure as a practical organizing principle for efficient differentiable simulation.

## 1. 论文核心问题与整体含义（研究动机与背景）

可微物理仿真（differentiable simulation）是机器人学习、控制、参数估计和反问题求解中的关键组件——在这些场景中，往往需要计算损失函数对物理仿真器输入（如材料参数、初始条件、控制信号等）的梯度，且这些梯度需要穿过非线性隐式求解器。

现有方案存在两条技术路径，但各有根本性缺陷：

- **展开自动微分（Unrolled AD）**：对求解器的每一次迭代进行显式展开并记录计算图，内存开销随求解器迭代深度线性增长，因而难以支撑大规模仿真。
- **方程级隐式微分（Equation-level implicit differentiation）**：直接对收敛后的非线性方程组进行隐式函数定理微分，需要组装全局雅可比矩阵并求解大型稀疏伴随系统。该方法不仅计算代价高昂，更关键的是，它丢失了前向求解器原有的局部性结构（locality），并且微分的是“收敛后的方程”而非“实际执行的有限步计算”——理论假设与实际计算过程脱节。

论文的核心洞察是：**求解器本身的结构（而非它所求解的方程）应作为微分的主要组织原则**。作者提出“求解器级微分”（solver-level differentiation），即直接对实际执行的那一个求解器算法进行精确微分，从而同时获得内存可扩展性、计算局部性以及梯度精确性。

## 2. 提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：对“执行的计算”而非“收敛的方程”求微分

当求解器由一系列**块隐式更新**（block implicit updates，即每次只对一组变量做隐式求解，而非对整个状态一次性求解）组合而成时，其离散伴随（discrete adjoint）可以通过**按逆序应用对应的伴随更新**来获得。这样得到的反向扫描公式（reverse-sweep formulation）使得反向传播过程精确地镜像（mirror）前向求解器。

### 2.2 算子层面的理解

- **前向传播**：通过一系列有序的局部求解（local solves）实现一个近似逆算子（approximate inverse）。
- **反向传播**：通过反向顺序应用局部伴随求解（reverse local adjoint solves），计算前向算子的转置（transpose）。
- 整个过程**无需构建任何全局系统**，实现了与求解器结构完全一致的“反向扫描”。

### 2.3 在 Vertex Block Descent（VBD）上的实例化

论文将这一框架具体应用于顶点块下降（Vertex Block Descent）求解器，得到如下关键构造：

- VBD 的前向更新本身由着色高斯-赛德尔扫描（colored Gauss-Seidel sweeps）组成，每个顶点块对应一个局部 3×3 线性系统求解；
- 反向传播等效于执行一次**伴随着色高斯-赛德尔扫描**，其中每一处反向更新完全由局部 3×3 伴随求解构成；
- 这样，反向传播的算法结构与前向求解完全对称，且不需要任何全局矩阵的组装或存储。

### 2.4 算法的通用性

作者进一步证明，同样的构造方法在**投影动力学**（Projective Dynamics, PD）和**扩展位置动力学**（Extended Position-Based Dynamics, XPBD）上也是**精确成立**（exact）的，说明该框架并非 VBD 所独有，而是适用于一类块隐式求解器范式。

## 6. 论文的主要结论与发现

1. **求解器级微分是精确的**：反向传播梯度与通过相同前向执行的自动微分梯度在机器精度上一致，且在所有求解器深度上均成立。
2. **方程级伴随存在本质偏差**：它求解的是“收敛方程”的伴随而非“实际计算”的伴随，在一次扫描后即产生 37% 的梯度误差——这证明对有限步非线性求解器而言，方程级隐式微分的理论前提在实际应用中并不成立。
3. **求解器级微分是高效的**：相比展开自动微分，实现了 33 倍加速与 71 倍内存削减——导致这种巨大差距的根本原因是反向传播不再需要记录和存储每一步的中间计算状态。
4. **求解器级微分是可扩展的**：成功在单 GPU 上处理 8M 顶点/100 万接触耦合软体，这是先前方法难以企及的规模。
5. **求解器结构是普适的组织原则**：该方法在 VBD、PD、XPBD 三个不同的块隐式求解器上精确成立，表明“将求解器结构作为微分的组织原则”是对一整类隐式可微仿真求解器普遍适用的方法论。

## 8. 不足与局限

- **求解器结构依赖性强**：方法依赖求解器可以分解为块隐式局部更新这一前提。对于不满足该结构的求解器（如直接法求解全局线性系统、预条件共轭梯度等非块结构求解器），该框架的应用方式需要重新推导，可能无法直接适用。
- **未覆盖更复杂的仿真场景**：实验主要集中在弹性体/软体动力学上，涉及接触耦合但并未深入验证流固耦合、断裂、极度大变形等复杂物理场景，其泛化性尚缺乏证据。
- **缺少深层迭代精度的显式分析**：虽然验证了“每一个求解器深度”上梯度与 AD 一致，但未显式讨论有限迭代深度对下游优化任务收敛性的影响，即“近似梯度”是否在不同深度下均对优化有效。
- **方程级伴随的对比并不完备**：37% 偏差这一结论仅在“一次扫描后”给出，未展示更多扫描次数下方程级伴随的误差变化曲线，读者无法判断该偏差是随迭代收敛而缩小还是保持。
- **硬件细节缺失**：未报告 GPU 型号、显存占用绝对值、前向/反向时间的具体数值，这限制了读者对方法实际资源需求的量化判断。
- **应用范围尚不完整**：论文没有展示在真实下游任务（如材料参数估计、控制策略学习）中的端到端效果，说明“梯度可用”尚未被证明为“下游任务收益显著”。
