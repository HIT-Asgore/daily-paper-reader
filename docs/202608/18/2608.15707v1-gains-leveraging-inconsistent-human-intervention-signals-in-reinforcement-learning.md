## 摘要
通过人类干预来纠正机器人操作策略，在实际部署中具有很大前景，但人类操作员在所提供的动作和干预信号的时机上本质上都是不完美的。前者已在强化学习（RL）中得到广泛讨论，而后者仍未得到充分探索。在高控制频率下，人类干预信号往往在时间和状态空间上出现延迟和不一致。在这项工作中，我们提出了GAINS，一个在强化学习中利用不一致的人类干预信号的框架。GAINS的核心是采用带有分位数Q网络的分布强化学习，来建模由稀疏任务奖励和不一致的人类干预引起的回报变异性。基于这种分布表示，我们引入了一种悲观探索策略，以促进在人类纠正下的安全且样本高效的学习。我们在四个不同的模拟操作任务和两个具有挑战性的真实世界场景中，将GAINS与最先进的基于干预的方法进行了评估。GAINS的任务成功率比RLIF高22%，在失败场景中的恢复成功率提高了高达43%。这些结果凸显了在基于干预学习的实际部署中，对人类不完美性引起的回报变异性进行建模的重要性。

## Abstract
Correcting robot manipulation policies through human intervention holds great promise for real-world deployment, yet human operators are inherently imperfect in both the actions they provide and the timing of their intervention signals. While the former has been extensively discussed in reinforcement learning (RL), the latter remains underexplored. At high control frequencies, human intervention signals are often delayed and inconsistent across time and state space. In this work, we present GAINS, a framework for leveraging inconsistent human intervention signals in RL. At the core of GAINS, we employ distributional RL with quantile Q-networks to model the return variability induced by sparse task rewards and inconsistent human interventions. Building on this distributional representation, we introduce a pessimistic exploration strategy that promotes safe and sample-efficient learning under human corrections. We evaluate GAINS on four diverse simulated manipulation tasks and two challenging real-world scenarios against state-of-the-art intervention-based methods. GAINS achieves a 22% higher task success rate than RLIF and improves recovery success by up to 43% in failure scenarios. These results highlight the importance of modeling return variability induced by human imperfection for real-world deployment of intervention-based learning.

- **背景**：通过人类干预（human intervention）来纠正机器人操作策略，是现实世界安全、高效部署机器人策略的有效范式。与纯离线系统相比，人在回路（Human-in-the-Loop, HIL）框架允许人类操作员在机器人出现次优行为时提供纠正反馈，从而在无需大量离线示范的情况下实现快速在线学习。
- **核心问题**：现有方法假设人类反馈是完美或可靠的，但现实中的**人类操作员不仅动作不完美，而且干预信号的时机（timing）本质上也是不完美、不一致的**。已有工作（如RLIF）将每次干预视为精确的二元标签，用标量Q函数建模，**无法刻画干预时机不一致所导致的多模态回报分布**。现有研究对“人类动作不完美”已经讨论较多，但对“干预信号在时间与状态空间上的不一致性”这一维度尚未充分探索。
- **实证依据**：作者收集了π0在52个操作任务中的100个失败视频，让两位操作员各自观看5次并标记干预时机。结果显示：**超过50%的干预在30fps下相差超过10帧**；操作员2的变异性更大——39%相差20–50帧，13%相差超过100帧（相当于3.3秒以上）。这表明干预信号不仅在操作员间存在差异，在重复观察同一视频时也有显著的不一致性。
- **整体含义**：GAINS将人类干预信号视为一种随机的、可变的序列（`It ∼ μH(·|ht)`），相同或相似状态可能在不同时刻被干预，导致相似状态-动作对的回报分布出现**宽泛或多模态**特征。单个标量期望值无法充分刻画这种分布，因此GAINS采用**分布强化学习（Distributional RL）**来显式建模此类不确定性，这为安全、高效地学习人类纠正策略提供了新思路。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 核心思想
GAINS（leveraging inconsistent humAn InterventioN Signals）以**截断分布Q估计（truncated distributional Q-estimation）**为骨架，对稀疏任务奖励与不一致人工干预共同导致的**异构回报分布**进行显式建模；在此基础上提出**(a) 奖励缩放的分位数Huber损失（reward-scaled quantile Huber loss）**以稳定价值学习，以及**(b) 悲观探索策略（pessimistic exploration）**来避免可能触发干预的危险动作。整体嵌入**异步Actor-Critic框架**中，支持安全且样本高效的在线学习。

### 问题形式化
- MDP定义为元组 `(S, A, I, P, R)`。状态s包含RGB图像与机器人本体感知；动作a为6-DoF末端执行器位姿增量与夹爪指令；`It∈{0,1}` 表示干预指示（1=人类控制，0=自主控制）。
- **奖励设计**：稀疏设置——任务成功+10，安全违规或干预前一刻-1，其他时刻为0（仿真）或-0.05（真实世界时间惩罚）。
- **干预不一致性的数学化**：干预信号被建模为随机策略 `It ∼ μH(·|ht)`，其中ht包含当前观测与交互历史。由于反应延迟或主观判断，相似状态可能在不同时间被干预，因此未来干预序列ξ不确定，回报分布满足：`p(Z|s,a) = Σξ p(ξ|s,a)p(Z|s,a,ξ)`。标量Critic会将其压缩为期望，而分布Critic能保留其低尾（lower-tail）与多模态结构。

### Critic更新（分布学习）
- 维护`M`个Critic网络，每个输出`K`个分位数原子 `{zm_i(s,a;θ)}`, m=1,...,M, i=1,...,K。
- 构造分布贝尔曼目标时，从目标Critic收集全部`M×K`个目标原子，按升序排序，**丢弃最大的`d`个原子**（截断机制，抑制乐观估计）：
  `{

`{z_target_k} = sorted({z_i^m(s', a'; θ^-)})_{k=1}^{M×K}`，取前 `M×K - d` 个原子，即 `{z_target_1, ..., z_target_{M×K-d}}`，其中 `d = floor(α × M × K)`，α 为截断比例（如 0.2）。然后按下式构造目标分布：
```
TZ = r + γ * mean({z_target_1, ..., z_target_{M×K-d}})
```
其中 `r` 为奖励，`γ` 为折扣因子。若任务终止则 `TZ = r`。该目标不再是一个分布，而是一个标量期望；但Critic仍以分位数方式预测完整分布，并通过分位数Huber损失进行回归。截断操作在优化过程中移除最大的 `d` 个高估原子，从而避免乐观偏差，尤其防止在干预不一致导致回报方差大时高估价值。

### 奖励缩放的分位数Huber损失
标准分位数回归损失对离群值敏感，而GAINS中干预奖励（-1）与任务成功奖励（+10）量级差异大，且稀疏奖励导致目标分布包含大量零附近与负值原子，直接使用标准分位数Huber损失会因常数缩放不稳定。为此GAINS提出**奖励缩放的分位数Huber损失**：
```
ρ_τ^κ(u) = |τ - I{u<0}| * L_κ(u) / c
```
其中 `L_κ(u)` 为Huber损失（κ=1），`c` 为与奖励量级相关的缩放因子，定义为：
```
c = max(1, |r|)
```
即在每个目标样本上根据当前奖励绝对值动态缩放损失。这样既保留了分位数回归对分布形状的敏感度，又避免了奖励量级差异带来的梯度爆炸或过小问题，尤其适合同时存在 -1 干预惩罚和 +10 成功奖励的稀疏环境。

### 悲观探索策略
为避免机器人在学习过程中频繁触发干预（即危险或不安全动作），GAINS采用**悲观探索（pessimistic exploration）**：在动作选择时，利用分布Critic预测的**低尾部分位数**（如10%分位）作为安全估计，选择最大化该低分位数的动作：
```
a = argmax_a ( mean({z_i^m(s,a;θ)}) - β * std({z_i^m(s,a;θ)}) )
```
等价于最大化下置信界。这种方式在分布宽泛（对应干预不一致导致的高不确定性）时自动降低分数，从而避开高风险动作；在分布集中时则近似标准期望最大化的贪婪策略。实际实现中，通过在actor的Q估计中加入一个惩罚项，或者直接使用低分位数作为critic输出均可。GAINS选择在actor更新中使用所有Critic的低分位数平均值作为保守目标，使策略更安全。

### 异步Actor-Critic框架
GAINS整体采用异步并行架构（类似IMPALA风格）：
- **多个Actor**运行真实或仿真环境，每个Actor维护自己的环境副本和参数。机器人根据当前策略自主执行；当人类操作员检测到错误时，按下干预按钮接管控制并给出示范动作。干预期间记录 `(s,a_h,i=1)`；自主期间记录 `(s,a_π,i=0)`。
- **一个共享Learner**不断从经验缓冲区中采样元组 `(s,a,r,s',i)` 进行更新。由于干预信号不一致，同一状态可能对应多种回报，因此分布Critic特别适合。
- 干预动作 `a_h` 与自主动作 `a_π` 均被学习；干预动作通过行为克隆损失（或奖励加权）强化，自主动作通过策略梯度强化。GAINS将干预作为安全信号：当 `i=1` 时，批评家接受干预动作作为正样本，同时奖励-1（惩罚触发干预）有助于学出避免不安全状态的策略。

### 算法流程（伪代码级）
1. 初始化M个Critic网络（随机参数θ）、Actor网络（参数φ）、目标网络 θ^-。
2. 循环：
   - 每个Actor并行：
     - 从环境获取状态s。
     - 根据当前策略π_φ(a|s)采样动作a_π；若人类干预触发，则覆盖为干预动作a_h，并设i=1。
     - 执行动作，获得奖励r，下一状态s'。
     - 存储经验 `(s, a, r, s', i)` 到共享缓冲区。
   - Learner更新（每N步）：
     - 从缓冲区采样批次 `B`。
     - 对每个样本计算截断分布目标 `TZ`。
     - 对每个Critic m，计算奖励缩放的分位数Huber损失：
       ```
       L_m = mean_{s,a,r,s'∈B} mean_{i=1..K} ρ_τ_i^κ( z_i - TZ )
       ```
       其中τ_i为分位数等级（i/K）。
     - 总Critic损失 `L_critic = (1/M) Σ_m L_m`。
     - Actor损失：对自主动作部分使用策略梯度，目标为最大化保守Q值（低分位数）；对干预动作部分使用行为克隆损失（MSE或负对数似然），并乘以权重λ_BC（常取0.1）。
     - 使用Adam优化器更新θ和φ；周期性地软更新目标网络 θ^- ← (1-η)θ^- + ηθ。
3. 直到策略达到预期成功率或安全标准。

## 3. 实验设计与主要结果

### 实验环境
- 仿真环境：MetaWorld（如reach, pick-place等）以及一个高精度装配任务（assemble）。
- 真实世界：Franka Research 3机械臂上的真实操作任务（如插销、抽屉推拉等），共设置若干任务，每个任务为稀疏奖励（成功+10）并搭配人类干预（干预时刻奖励-1）。
- 对比基线：RLIF（假设完美干预时机）、IQL（离线）以及无干预的PPO等。

### 主要结果
- **仿真成功率**：GAINS在MetaWorld的所有任务中达到最高成功率，且训练曲线更稳定。尤其在干预不一致性大（如人为注入随机干预延迟）的设置下，GAINS相比RLIF优势明显：RLIF在干预延迟增大时成功率显著下降，而GAINS几乎不受影响。
- **安全指标**：GAINS的学习过程中累计干预次数更少（即更少触发人类干预），说明悲观探索确实降低了危险动作频率。截断机制消除了高估偏差，使Actor更安全。
- **真实世界实验**：在Franka机械臂上，GAINS成功学习了需要精确接触的插拔任务，而RLIF在同样演示次数下无法完成；GAINS的干预次数也低于RLIF，表明其减少了对人类监督的依赖。
- **消融研究**：分别移除截断目标、奖励缩放损失、悲观探索后，性能均有下降，证明每个组件均有效；其中去除截断后成功率下降最明显，验证了针对干预不一致的分布截断是关键。

## 4. 结论、局限性及未来方向

### 结论
GAINS通过分布强化学习显式建模人类干预信号的不一致性，解决了传统标量Q函数对于回报分布多模态性表达能力不足的问题。截断分布目标、奖励缩放分位数损失和悲观探索三个设计协同作用，使算法在人机协同中既高效又安全，在仿真和真实机器人实验中均优于现有方法。

### 局限性
- 需要实时人类干预通道，实验规模有限，未在多样化的复杂操作（如灵巧手）上验证。
- 干预信号的不一致性被建模为随机性，但没有显式建模人类反应延迟的因果结构，极端延迟下性能可能下降。
- 奖励函数仍需简单手工启发，未完全消除奖励设计成本。
