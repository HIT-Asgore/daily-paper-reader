## 摘要
世界动作模型联合预测未来的视觉观测和动作，而现有的触觉感知变体通常将未来触觉表示为图像或潜在流，而不建模以分层方式组织触觉状态的物理依赖关系。我们提出了HiTac-WAM，一种分层触觉世界动作模型，在执行前为每个候选动作块预测一系列未来触觉状态。预测分解为接触状态、三维变形场和滑移风险，组织为有向层次结构，其中每个后续阶段都以前一阶段的停止梯度信号为条件。有向注意力掩码允许触觉查询关注每个候选的视频-动作上下文，同时防止视频和动作查询关注触觉令牌。对于规划，HiTac-WAM使用触觉预测和任务进度估计对候选动作块进行排序。对于执行，保留选定的触觉预测作为参考；预测与观测触觉状态之间的持续差异触发纠正性重新规划。HiTac-WAM的平均接触F1为0.921；在匹配的训练预算下，有向层次结构相对于仅变形预测器将三维位移L2误差降低17.6%，相对于仅滑移预测器将滑移AUPRC提高60.4%。在芯片抓取、黑板擦除和USB插入任务中，由分层预测引导的选择将平均真实机器人成功率从31.1%提高到61.1%，而完整系统达到72.2%。

## Abstract
World action models jointly predict future visual observations and actions, whereas existing tactile-aware variants typically represent future touch as an image or latent stream without modeling the physical dependencies that organize tactile states hierarchically. We present HiTac-WAM, a hierarchical tactile world action model that forecasts a sequence of future tactile states for each candidate action chunk before execution. The forecast factorizes into contact state, a 3D deformation field, and slip risk, organized as a directed hierarchy in which each downstream stage is conditioned on stop-gradient signals from preceding stages. A directed attention mask allows tactile queries to attend to the video-action context of each candidate while preventing video and action queries from attending to tactile tokens. For planning, HiTac-WAM ranks candidate action chunks using tactile forecasts and task-progress estimates. For execution, the selected tactile forecast is retained as a reference; persistent discrepancies between predicted and observed tactile states trigger corrective replanning. HiTac-WAM achieves a mean contact F1 of 0.921; under matched training budgets, the directed hierarchy reduces 3D displacement L2 error by 17.6% relative to the deformation-only predictor and improves slip AUPRC by 60.4% relative to the slip-only predictor. Across chip grasping, blackboard erasing, and USB insertion, selection guided by the hierarchical forecasts increases the average real-robot success rate from 31.1% to 61.1%, while the full system attains 72.2%.

### 1. 论文的核心问题与整体含义

**研究动机**：接触丰富的机器人操作（如抓取、插拔）中，接触状态（接触时机、压力、滑移）往往无法通过视觉可靠观测，尤其在遮挡条件下。现有世界动作模型虽能联合生成视觉与动作，但其触觉预测通常将接触、形变、滑移混在单一流中，或将其视为相互独立的目标，未显式建模它们之间的物理依赖关系（无接触则无形变，无接触与形变则无滑移风险），导致触觉预测精度受限，且较难直接用于候选动作的评估与选择。

**问题定义**：在执行前，如何为每个候选动作块预测未来触觉后果，并利用该预测进行动作排序、执行监控与在线重规划，以提升真实机器人接触丰富任务的成功率。

**意义**：HiTac-WAM 通过将触觉预测显式分解为"接触状态 → 3D形变 → 滑移风险"的有向层次，并保留预测与候选动作的配对关系，统一解决了候选评估与执行期验证问题，在三个真实任务上显著提升成功率，为触觉世界模型提供了新的建模范式。

### 2. 方法论：核心思想、关键技术细节与算法流程

**核心思想**：在执行候选动作块前，对每个候选预测一条有结构的触觉轨迹，按物理依赖顺序组织为层次结构：接触状态决定形变是否有意义，接触与形变共同决定滑移风险；预测结果用于候选排序，执行时保留所选预测作为参考，偏差持续超阈值则触发重规划。

**整体框架**（图1、图2）：
- 以预训练世界动作模型为基础，增加触觉分支；
- 对每个采样候选动作块 \(A^{(k)}_{t} \in \mathbb{R}^{H\times 7}\)，预测未来触觉状态 \(\hat{T}^{(k)}_{t+1:t+H} = (\hat{C}, \hat{D}, \hat{R}_{\text{slip}})\)，覆盖 H=24 步。

**关键设计 1：有向注意力掩码**
- 注意力矩阵中按"视觉–动作–触觉"顺序划分块；
- 触觉查询（query）可关注视觉/动作上下文与触觉历史；
- 视觉与动作查询不可见触觉键值，防止触觉信息干扰视觉/动作生成，同时让触觉预测感知候选动作与对应视觉未来。

**关键设计 2：显式层次化触觉预测**
- 预测公式（表意，非精确重现）：
  - 接触状态：\(\hat{C} = \sigma(f_C(z, a))\)
  - 形变增量：\(\Delta\hat{D} = f_D(z, \text{sg}(z_C), a)\)，门控输出 \(\hat{D} = \hat{C} \odot (D_t + \Delta\hat{D})\)
  - 滑移风险：\(\hat{p}_{\text{slip}} = \sigma(f_R(z, \text{sg}(\hat{C}), \text{sg}(D_t + \Delta\hat{D}_2)))\)，\(\hat{R}_{\text{slip}} = \hat{C} \cdot \hat{p}_{\text{slip}}\)
- 停止梯度（stop-gradient）保证下游损失不直接回传更新上游预测头，但共享特征仍耦合三者。

**关键设计 3：预测引导的候选选择**
- 每个候选的预测被压缩为归一化代价：\(J_C\)（接触相位不一致）、\(J_D\)（形变过大/双侧失衡）、\(J_R\)（滑移峰值与均值）；
- 与视觉 rollout 的任务进度估计共同构成总分 \(J^{(k)} = -w_{\text{prog}}\rho_{\text{task}} + w_C J_C + w_D J_D + w_R J_R\)，取最小者作为执行动作。

**关键设计 4：在线预测验证**
- 执行已选动作块前 E=8 步前缀，每步将实测触觉与保留的预测比对，计算标准化残差；
- 通过任务相关 KDE 拟合得分分布，连续 3 步超阈值则触发安全撤退、重新观测与重新生成候选（至多两次纠正）。

**损失函数**：接触损失（BCE + 接触开始/释放加权）+ 形变 Huber 损失（仅在真实接触帧上监督）+ 滑移加权二分类损失（正样本权重30）。

### 3. 实验设计：数据集/场景、Benchmark 与对比方法

**实验平台**：IMETA-Y1 机械臂 + 双臂 DM-Tac W2 触觉传感器 + 3 个 RGB 摄像头（2个 RealSense D435i + 1个 USB 摄像头），全部实验固定硬件。

**任务场景**（3 个接触丰富的真实操作任务）：
- 芯片抓取（Chip Grasping）：完整芯片拾取至目标盘，稳定3秒；
- 黑板擦除（Blackboard Erasing）：沿指定路径有效接触并擦除目标区域80%以上；
- USB 插入（USB Insertion）：完全插入且无持续卡住、连接器 LED 亮起。

**数据规模**：每任务 200 个完整 episode，按 160/20/20 分割为训练/验证/测试，窗口不跨分割。标注包含双侧接触标签、滑移事件、3D形变场（无接触状态为参考零位），数据同步 30Hz。

**对比方法**（表 I 主比较，每方法-任务对 30 次试验，共 360 次）：
- **DreamZero**：同世界动作模型但无触觉分支，只执行单个采样动作块；
- **Reactive Tactile**：执行时使用当前触觉反馈，但无触觉预判（用当前触觉而非预测触觉）；
- **Task-progress ranking**：4 个随机候选按视觉任务进度排序，无触觉预测（额外 90 次试验）；
- **HiTac-WAM Selection**：4 个候选按触觉预测 + 任务进度排序；
- **Full HiTac-WAM**：Selection + 在线预测验证/重规划。

**消融实验**：接触预测器、形变预测器、独立多头预测器、接触条件化、完整层次结构（表 III）；接触条件化干预（GT/predicted/shuffled/zero contact，图 5a）；滑移条件化阶梯（图 5b）。

### 6. 论文的主要结论与发现

- **触觉预测质量**：平均接触 F1 达 0.921，接触开始/释放时间误差约 2.1/2.3 帧（30Hz 下约 60–87 ms），3D 形变 L2 误差 0.058 mm，滑移 AUPRC 0.247（远超随机水平 0.0139）。
- **层次结构的价值**：在匹配训练预算下，独立多头预测（共享表示但不显式依赖）表现不优于单任务预测器，说明单纯共享特征不够；显式层次结构使形变 3D L2 误差降低 **17.6%**（0.068→0.056 mm）、滑移 AUPRC 提高 **60.4%**（0.154→0.247，以滑移仅为 0.154 时为基准），预测形变大小与真实值接近（norm 比 0.96–0.99）。
- **选择机制的作用**：触觉预测引导的选择将成功率从单候选执行的 **31.1%** 提升到 **61.1%**；在固定 K=4 预算下优于视觉任务进度排序（61.1% vs. 35.6%），且 Wilson 置信区间不重叠。
- **在线验证进一步增益**：完整系统（选择 + 重规划）将平均成功率提升至 **72.2%**，其中 18 次重规划触发中 16 次对应实际异常、12 次随后成功完成，至多 3 例未触发重规划的失败存在遗漏异常。
- **对视频/动作生成影响小**：相较无触觉世界模型，视频 LPIPS 和动作 MAE 仅分别上升 1.4% 和 0.9%。

### 7. 优点

- **建模视角新颖**：将触觉预测按物理依赖组织为有向层次（接触→形变→滑移），停止梯度与共享特征结合，既显式建模依赖又保留端到端学习能力，这比单流或独立多任务预测更有物理合理性。
- **预测与决策闭环**：每个触觉预测保持与其候选动作配对，先用于排序、后保留作执行参考，实现"预测 → 选择 → 执行 → 验证 → 重规划"完整闭环，将候选评估与在线监控统一在同一框架内。
- **有向注意力掩码设计**：让触觉查询利用视频/动作上下文，又不反向干扰视觉/动作生成，解耦了模态间的信息流方向，设计简洁有效。
- **实验较扎实**：真实机器人多任务验证，含多层次消融、干预诊断和失败案例分析，证据链相对完整；指标覆盖预测精度、决策收益和系统级成功率。

### 8. 不足与局限

- **预测对象局限**：未单独评估使用模型生成动作块时的预测质量（文中训练/评估数据以人类演示或策略产生的动作为主），模型生成的分布外动作可能导致预测失真。
- **滑移预测未校准为在线检测器**：滑移 AUPRC 0.247 虽远好于随机，但作者坦承这是排序信号而非校准风险报警；且滑移正样本仅占 1.39%，在线检测敏感度可能受限，未来需不确定性校准。
- **在线验证分析与阈值依赖**：检测器统计来自事后人工检查而非系统标注；KDE 阈值 γ_task 和连续步数（3步）等超参数依赖验证集校准，跨任务泛化性未知。
- **比较公平性瑕疵**：固定预算对比中触觉排序与任务进度排序的实验为独立执行而非同一批候选下的对照，作者也自述该比较为描述性而非严格假设检验；主比较中的 DreamZero（无触觉但单候选）与 Selection（4 候选）之间的成功差距也可能部分来自候选采样数量而非触觉信息本身。
- **任务范围有限**：三个任务均集中在刚性/半刚性接触，未覆盖柔性形变、双机械臂协调或长时程多阶段任务；硬件平台单一（IMETA-Y1 + 特定触觉传感器），跨平台泛化性尚待验证。
- **算力信息不全**：未提供训练总时长、模型参数量、推理时延等关键资源指标，难以评估实际部署成本。
