## 摘要
腿式机械臂通过将敏捷运动与多功能臂控制相结合，扩展了机器人超出静态操作的能力。然而，在保持协调运动的同时实现精确操作仍是一项重大挑战。本文提出了一个分层强化学习框架，用于使用配备6自由度机械臂的四足机器人执行动态抓取与放置任务。该框架包含一个显式质量估计模块，能够对具有不同重量的物体实现自适应全身控制。在仿真中，该系统在负载高达2.3 kg时实现了86.05%的成功率。该方法通过六种代表性场景的真实世界实验进一步验证，这些场景中物体物理属性（尺寸和质量）和任务高度受控变化。具体来说，在从地面到1.1米高桌面的广泛垂直工作空间内，该系统在负载高达1.3 kg时展示了73.3%的平均成功率，平均执行时间为4.06秒。与先前处理轻量物体并以缓慢、分段运动执行抓取与放置动作的工作不同，所提出的框架利用并发运动与操作实现动态、连续执行。这些结果证明了四足移动机械臂在更重负载和扩展工作空间下进行自适应全身抓取与放置的潜力。

## Abstract
Legged manipulators extend robotic capabilities beyond static manipulation by integrating agile locomotion with versatile arm control. However, achieving precise manipulation while maintaining coordinated locomotion remains a major challenge. This work presents a hierarchical reinforcement learning framework for dynamic pick-and-place tasks using a quadruped equipped with a 6-DOF robotic arm. The framework incorporates an explicit mass estimation module enabling adaptive whole-body control for objects with varying weights. In simulation, the system achieves an 86.05% success rate with payloads up to 2.3 kg. The approach is further validated through real-world experiments across six representative scenarios with controlled variations in object physical properties (size and mass) and task heights. Specifically, within a wide vertical workspace ranging from ground level to 1.1~m-high tabletops, the system demonstrates an average success rate of 73.3% for payloads up to 1.3 kg, with an average execution time of 4.06 s. Unlike prior works that handle lightweight objects and execute pick-and-place motions with slow, piecewise motions, the proposed framework exploits concurrent locomotion and manipulation for dynamic, continuous execution. These results demonstrate the potential of quadrupedal mobile manipulators for adaptive, whole-body pick-and-place with heavier payloads and extended workspaces.

## 1. 核心问题与研究动机

- **背景**：腿式机械臂（四足机器人+机械臂）相比固定基座或轮式机器人，具有更高的自由度和地形适应能力，能够执行复杂的移动操作任务。然而，动态操作面临两大挑战：一是运动时基座振荡会放大到末端执行器，影响精确性；二是机械臂运动产生的反作用力会干扰基座姿态稳定。
- **核心问题**：现有基于强化学习（RL）的腿式操作方法大多局限于轻量物体、准静态分段执行（如先停稳再抓取），无法充分利用四足机器人的动态运动能力和全身协调性。本文旨在实现**动态、连续、快速的抓取-运输-放置**全流程，同时支持较重的负载和大幅高度差（地面到1.1米高桌面）。

## 2. 方法论：核心思想与技术细节

### 2.1 整体架构：分层强化学习（Hierarchical RL）
- **低层控制器（Low-level）**：频率100 Hz，负责全身运动稳定（腿部和基座调节）。输入为基座速度指令、俯仰与高度指令，输出12个腿部关节目标位置。它通过强化学习在模拟中训练，并使其能够抵抗随机的机械臂扰动（使用“随机臂运动生成器”产生多样化动态干扰）。
- **高层控制器（High-level）**：频率50 Hz，负责任务级决策（抓取、运输、放置、撤回）。输入包括机器人本体状态、物体状态（三关键点表示）、任务参数（拾取和放置表位姿）、阶段索引等，输出基座控制指令（速度、高度、俯仰）和机械臂关节目标位置+夹爪状态。
- **关键设计**：低层训练时冻结高层；高层训练时冻结低层；高层动作空间中基座速度、高度、俯仰作为可控变量，允许灵活调整全身构型。

### 2.2 在线质量估计模块
- **动机**：物体质量直接影响动态操作中的力和平衡，且无法直接感知。
- **方法**：使用LSTM网络，在高层训练时以物体质量和抓取接触状态作为“特权信息”进行监督；在推理时仅从历史状态（状态、动作、物体信息）中隐式估计。该估计结果被添加到高层观察中。
- **效果**：相比无估计模块的基线，在分布外（2.3-3.0 kg）质量区间成功率提升4.2%；估计值在抓取后迅速收敛到真实值。

### 2.3 基于成功率的课程学习（Curriculum Learning）
- 将任务难度参数（拾取距离、放置距离、物体质量等）与三个子目标成功率关联，逐步增加难度。
- 使用同步约束防止“偏科”：拾取和放置难度只有当两者差距小于阈值时才同时增加。

### 2.4 奖励函数设计
- 任务分解为6个阶段（预抓取、抓取、携带、放置、撤回、完成），每个阶段仅激活对应子目标的奖励项。
- 综合使用稀疏奖励（成功信号）和密集奖励（引导接近），并加入正则化惩罚（关节速度/力矩、基座加速度、接触力等）。

## 3. 实验设计

### 3.1 仿真实验
- **环境**：使用Raisim模拟器，两个圆柱形桌子（半径10 cm），物体为圆柱或长方体，任务参数随机化范围见表I（距离0.9-3.0 m，高度0-1.3 m，质量0.2-2.3 kg）。
- **基线方法**：

  3. Segmented Policy：类似ASC[10]，分别训练接近-抓取和运输-放置两个策略并顺序执行。

### 3.2 真实世界实验
- **场景**：6个场景（见表VI）：
  - Nominal（0.83 kg，高度0.6↔0.9 m）
  - Heavy Object（1.3 kg）
  - Light Object（0.47 kg）

  - Large Size（φ7×10 cm）

- **设置**：每场景10次试验，初始位置随机；使用Vicon动捕系统获取物体和桌子位姿；决策频率50 Hz（高层）/100 Hz（低层）。

## 6. 主要结论与发现

- 提出的分层强化学习框架能够实现四足移动操作器的**动态连续抓取放置**，速度比先前准静态方法（如ASC）快约10倍（4.06 s vs 43.8 s）。

## 7. 优点

1. **创新性**：首次在腿式操作中实现“边运动边抓取”，基座与手臂协调高速运动，而非停稳再操作。

5. **方法论清晰**：分层分解、显式质量估计、成功驱动课程学习等设计使得训练高效且稳定。

## 8. 不足与局限
