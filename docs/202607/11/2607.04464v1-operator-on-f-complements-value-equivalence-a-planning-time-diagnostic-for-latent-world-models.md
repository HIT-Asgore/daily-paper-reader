## 摘要
对于基于模型的强化学习，世界模型评估通常询问学习到的模型是否能很好地预测奖励和价值，这可能遗漏模型中潜在 rollout 中与规划相关的错误。我们引入了一种互补的诊断方法——关于F的算子，它通过模型自己的预测器，在可观测子集F上比较模型的k步潜在前推与环境的前推。在 cheetah-run 上的 TD-MPC2 大小扫描中，每个模型大小的奖励预测误差保持在 [0.028, 0.091] 范围内——仅约3倍变化，因此未归一化的奖励拟合检查的分辨率较窄，难以区分它们；未归一化的贝尔曼残差和奖励误差本身与回报的关系较弱（Spearman 分别为 -0.10 和 -0.30）。算子误差在相同大小范围内从 0.28 到 2.62。在 317M 时，算子误差为 2.62——比 0.28-0.36 的聚类高一个数量级——规划回报降至 0.9，而奖励预测误差（0.091）是五个中最大的，但仍保持在与其他扫描相同的 [0.028, 0.091] 小范围内。算子误差与回报损失之间的秩相关性为 -0.90（n=5 个大小时的锚定自助法 95% CI [-0.90, -0.70]；留一法移除任意单个大小后仍为 -0.80 或更强）。该算子在 TD-MPC2 和纯自监督学习潜在世界模型之间的跨架构比较中也提供了信息丰富、区分架构的估计。算子诊断补充了价值等价性，而非替代它。

## Abstract
World-model evaluation for model-based reinforcement learning typically asks whether the learned model predicts reward and value well, which can leave planning-relevant errors in the model's latent rollouts unmeasured. We introduce a complementary diagnostic, operator-on-F, that compares a model's k-step latent pushforward to the environment's on an observable subset F, using the model's own predictor. On a TD-MPC2 size sweep over cheetah-run, reward-prediction error stays within [0.028, 0.091] for every model size - only about 3x variation - so an unnormalized reward-fit check has narrow resolution to distinguish them; the (unnormalized) Bellman residual and reward error themselves have weak relationships with return (Spearman -0.10 and -0.30). Operator error spans 0.28 to 2.62 over the same sizes. At 317M the operator error is 2.62 - an order of magnitude above the 0.28-0.36 cluster - and the planning return collapses to 0.9, while reward-prediction error (0.091) is the highest of the five but stays within the same small [0.028, 0.091] range as the rest of the sweep. The rank correlation between operator error and return loss is -0.90 (anchor-bootstrap 95% CI [-0.90, -0.70] at n=5 sizes; leave-one-out removal of any single size leaves it at -0.80 or stronger). The operator also returns informative, architecture-discriminating estimates in a cross-architecture comparison between TD-MPC2 and a pure-SSL latent world model. The operator diagnostic complements value-equivalence rather than replacing it.

- **研究动机**：价值等价性（value-equivalence）认为模型只需要正确预测奖励和价值即可用于规划，但实验发现，奖励预测误差很小的模型（如TD-MPC2在cheetah-run上奖励误差仅0.028-0.091）仍可能出现规划崩溃（如317M模型回报降为0.9）。这说明现有评估指标缺乏对潜在动力学误差的敏感性。
- **整体含义**：本文提出一种互补诊断方法——operator-on-F，通过比较模型k步潜在前推（pushforward）与环境真实前推在可观测子集F上的差异，直接测量模型在规划时间步上的动力学错误，为世界模型评估提供更细粒度的视角。

### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：在模型自身的潜在空间上，利用其预测器（latent predictor）对可观测子集F（如奖励、价值、PCA基等）进行k步展开，并与环境编码后的真实下一步进行比较。通过归一化误差（除以真实前推的跨锚点标准差）来获得尺度不变的度量。
- **关键技术细节**：
  - 定义每个锚点（anchor）的算子误差：\( e_{\phi}(t) = \frac{|\phi(\hat{z}_{t+k}) - \phi(z'_{t+k})|}{\sigma_{\phi}} \)，其中 \(\hat{z}_{t+k}\) 是模型预测的潜在状态，\(z'_{t+k}\) 是环境编码后的真实状态，\(\sigma_{\phi}\) 是真值前推的标准差。
  - 聚合方式：对每个可观测函数ϕ，在锚点上取均方根（RMS），再对F中所有ϕ取RMS得到最终值。
  - F的选择：价值切片（F = {r, V}）以及全F（价值切片 + 基于环境编码的PCA基（前16个主方向，经奇异值白化））。PCA基在保留的一半锚点上拟合，在另一半上评估，避免过拟合。
  - 探针（probe）：使用带正则化的岭回归（ridge regression）将潜在编码映射到F，正则化系数λ通过网格搜索确定，并报告R²以证明探针质量。同时用1隐藏层MLP探针做消融。
- **与价值等价性对比**：operator-on-F使用自身预测器在规划时间步上的k步展开，而非像价值等价性那样依赖奖励/价值头预测；且归一化处理使其能区分不同规模模型。

### 6. 论文的主要结论与发现
- **operator-on-F比传统指标更敏感**：在TD-MPC2规模扫描中，operator-on-F误差范围0.28–2.62（317M时跃升为2.62），而奖励预测误差仅0.028–0.091（3倍变化）。算子误差与回报损失的秩相关性高达−0.90（95% CI [−0.90, −0.70]），留一法仍≥−0.80。
- **传统指标误导**：未归一化的贝尔曼残差和奖励误差与回报相关性弱（分别为−0.10和−0.30），甚至正向相关（如贝尔曼残差与算子误差的Spearman为+0.30）。
- **归一化是关键**：经归一化后，价值切片（F={r, V}）的算子误差也能达到与全F相似的回报相关性（−0.90~−1.00）。表明operator-on-F的主要贡献是归一化和共享可观测基。
- **跨架构区分力**：在共享F上，LeWM的operator-on-F误差（0.384±0.009）远低于单任务TD-MPC2（0.840），置信区间不重叠，且经MLP探针消融后仍保持（LeWM 0.494±0.006 vs TD-MPC2 0.997）。说明该诊断能反映不同架构的动力学建模质量。
- **补充性而非替代**：operator-on-F不是要否定价值等价性，而是在其失效时提供额外信息，建议两者同时报告。

### 7. 优点
- **方法论创新**：提出了一个直接比较潜在动力学前推的规划时诊断，不依赖奖励/价值头，适用于无奖励头的模型。
- **归一化处理**：通过除以真实前推标准差，使误差尺度对模型规模不敏感，提高了分辨率（3倍 vs 10倍跨度）。
- **探针设计严谨**：使用带正则化的岭回归、报告R²、MLP探针消融、常见良好探针子集控制，排除了探针容量不对称导致的偏差。
- **统计严谨**：使用锚点自助法计算置信区间、留一法检验秩稳定性，报告部分相关性。
- **可解释性**：证明了算子误差与回报的强负相关性（−0.90），说明该度量与规划质量直接相关。

### 8. 不足与局限
- **实验覆盖有限**：仅在一个环境（cheetah-run）上做了完整扫描，跨架构比较只有两个点，且缺少重建锚点模型（如DreamerV3）做中间基准。
- **样本量小**：规模扫描仅5个点（n=5），虽然留一法稳定，但统计效力不足，不能推广到一般规律。
- **计算资源未报告**：缺乏训练和评估的GPU型号、数量、时间等细节，可复现性受限。
- **探针依赖**：虽然做了控制，但不同潜在几何上共享F仍需通过探针读出，探针质量可能影响结果。
- **单环境观察**：317M模型在其他任务上表现正常，说明该现象不是全局的，operator-on-F的泛化性需更多任务验证。
- **未与Koopman算子等现有方法深入对比**：仅简短提及，未做定量比较。
