## 摘要
非抓取操作通常作为机器人抓取前的准备步骤，但现有方法通常需要预定义的目标物体位姿。然而在实践中，物体存在多个可抓取的构型，且期望位姿事先未知。我们将用于抓取的非抓取操作重新定义为优化一个以物体为中心的可抓取性目标，而非达到特定位姿。我们通过合成抓取构建可抓取集，并定义了一个可抓取场，用以衡量物体构型对成功执行抓取的适用程度。该标量度量提供了密集的学习信号用于强化学习，并决定了何时终止操作。这产生了一个由单一策略驱动的闭环操作到抓取流程。在仿真和真实机器人上的实验表明，该策略能够可靠地将物体重新配置为可抓取状态，并过渡到抓取，无需外部规划器或手动指定的停止条件。预测的可抓取距离与真实世界抓取成功相关，表明所学表示捕获了物体构型的抓取可行性。

## Abstract
Non-prehensile manipulation is often used as a preparatory step for robotic grasping, yet existing approaches typically require a predefined target object pose. In practice, however, objects admit multiple graspable configurations and the desired pose is not known in advance. We reformulate non-prehensile manipulation for grasping as optimizing an object centric graspability objective rather than reaching a specific pose. We construct a graspable set from synthesized grasps and define a graspability field that measures how suitable an object configuration is for successful grasp execution. The scalar measure provides a dense learning signal for reinforcement learning and determines when to terminate manipulation. This yields a closed-loop manipulation-to-grasp pipeline driven by a single policy. Experiments in simulation and on a real robot show that the policy reliably reconfigures objects into graspable states and transitions to grasping without external planners or manually specified stopping conditions. The predicted graspability distance correlates with real world grasp success, which indicates that the learned representation captures grasp feasibility of object configurations.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有非抓取操作（pushing/reorienting）作为抓取准备步骤时，通常要求预定义物体的目标位姿（target pose）。然而实际中，物体往往存在多个可抓取构型（graspable configurations），且期望的抓取位姿事先未知。预定义目标破坏了操作灵活性：即使达成目标位姿，物体可能仍不可抓取；反之，远离目标的构型可能更易抓取。
- **整体含义**：作者主张重新定义非抓取操作的目标——不是达到特定姿态，而是优化物体自身构成对抓取的适宜程度，即“可抓取性”（graspability）。通过构建可抓取性场（graspability field），使操作策略直接以提升该场值为驱动，并自动决定何时终止操作转为抓取，形成无需外部规划器的闭环管道。

## 2. 论文提出的方法论

- **核心思想**：学习一个定义在物体构型空间上的可抓取性场，该场输出标量值衡量当前构型对执行稳定抓取的适宜程度。操作策略的目标是最大化终态场值，而非靠近某个预设姿态。
- **关键技术细节**：
  1. **可抓取集构建**：利用现成抓取合成模型（SE(3)-DiffusionFields）对物体点云预测多个候选抓取，将每个抓取转换为物体参考位姿（固定垂直顶部抓姿，物体落在桌面上），形成可抓取集 Sg。
  2. **可抓取性场定义**：当前物体构型 so 的可抓取性距离定义为到 Sg 的几何相似度距离。为平滑训练，使用 soft-min 聚合所有参考距离，并加入基于前一步选择的锚定项以减少振荡：
     \[
     \tilde{d}(s_o) = d_{\text{soft}}(s_o) + \lambda\, D(s_o, \hat{s}_{i^*_o})
     \]
     其中 D 基于关键点的平均欧氏距离。该距离越小，可抓取性越高。
  3. **强化学习奖励**：将可抓取性距离转化为势能函数，使用势能奖励塑造（potential-based reward shaping）：
     \[
     r_t = \gamma \Phi(s_{o}^{t+1}) - \Phi(s_o^t),\quad \Phi(s_o) \triangleq k_1 \beta^{k_2 \tilde{d}(s_o)}
     \]
     奖励随着距离减小（场值增大）而正向反馈。
  4. **教师–学生策略架构**：教师策略（有完整物体观测）通过 PPO 训练，再蒸馏出学生策略（仅部分点云+GRU时序聚合）。学生还预测可抓取性距离和最终抓取位姿。
  5. **操作–抓取过渡判断**：用预测的归一化距离（除以物体对角线长度）在时间窗口内持续低于阈值 ϵ 来判断物体已进入可抓取状态，自动切换到抓取执行。

- **算法流程**（文字说明）：
  训练阶段：通过合成抓取生成参考位姿集 → 在仿真中教师策略用基于可抓取性场的奖励进行RL → 学生从教师蒸馏（行为克隆+距离回归+抓取位姿监督）。
  推理阶段：学生策略接收部分点云和机器人状态 → 输出操作动作和预测距离 → 当预测距离满足阈值时，执行预测的抓取位姿。

## 7. 优点

- **概念创新**：首次将非抓取操作明确形式化为可抓取性优化，避免了预定义姿态的不灵活。

- **无目标泛化**：无需指定目标姿态，自动适应不同物体的可抓取区域；在未见物体上泛化良好。
- **闭环流程**：学生策略端到端预测动作和可抓取距离，实现从操作到抓取的自动过渡。
- **实验设计较完整**：涵盖了仿真对比基线（含oracle上限）、真实世界验证、多种物体和消融，结果清晰。
